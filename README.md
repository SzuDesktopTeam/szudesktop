## 装上之后，可以做什么？

- **找学校通知**：选学院、搜关键词，直接读公告正文、找附件，不必逐个翻学院网站。
- **去图书馆借书**：输入书名或作者，查馆藏位置、索书号和在架状态，出发前知道去哪里找。
- **整理一门课**：按课程写笔记、全文搜索；选中不懂的一句话变成待办，开始一段专注复习。
- **看学业与校园生活**：自动校历和成绩表导入算绩点；另有课表、场地时段、电量等学校查询，测试范围见下文。
- **连接校园网**：支持教学区、宿舍区认证，连不上时分别检查外网、校园认证和门户状态。
- **养一位桌面伙伴**：它可以留在桌面上，点开菜单摸头、喂食、切换形象；专注奖励用于庭院种植与建设。

**免费、开源，无广告、无充值。** 笔记、待办、专注和庭院离线可用，无需学校账号。公告与馆藏联网即可查；个人业务需要本人学校权限，部分仍在测试。项目由学生制作，与深圳大学无隶属或背书关系。

## 学校公告：找到自己学院的通知

**想找奖学金、选课、答辩或讲座通知？选来源、搜关键词，再打开正文和附件。**

- **按学院看**：17 个学院的通知可以在应用里阅读，另有教务部和研究生院来源；列表显示标题、日期与来源。
- **查以前的通知**：18 个来源接入学校的标题／全文检索，可以翻页查历史结果。搜索范围会标清是通知栏目还是单位网站。
- **点开就读**：展开正文，打开附件；随时可回学校原文核对。
- **读完就行动**：把学校公告加入待办，自己写计划日期、改成具体要做的事；之后从待办直接回原文找材料和要求。

例如：选择自己的学院，搜索「奖学金」，查看通知里的申报条件与附件。材料学院目前只筛选已读取的标题；其余未接入的学院提供官网入口。[公告与校园服务指南 →](docs/guide/campus.md)

## 学业：课表、校历、培养方案与绩点

**现在就能用：看教学周，把自己的成绩表整理成学分和绩点统计。**

- **自动校历**：读取官方校历，显示学期与教学周；更新失败保留缓存，调课或特殊安排可自行对照学校通知，也支持手动调整周次。
- **成绩表导入**：从 Excel 或学校成绩表复制内容，或导入 CSV / TSV，先预览再保存。按学期、培养层次筛选，并选择重修、免修等课程是否计入，计算学分加权绩点。本科支持等级换算并优先使用官方绩点；研究生使用成绩表里的官方绩点。

**以下学校在线查询已接入，仍在测试，需要本人账号验收：**

| 想查什么 | 应用准备怎样呈现 |
| :-- | :-- |
| 我的课表 | 选择本科或研究生，在学校窗口登录后手动读取课程安排、时间与地点 |
| 在线成绩 | 读取学校返回的课程成绩；与本机成绩导入分开，不自动并入绩点统计 |
| 全校课表 | 按学期、班级、年级、学院或专业查询，再看排课、调课、实践课与未排课程 |
| 培养方案 | 检索已发布方案，展开模块要求和课程明细；不等于本人已修学分 |

Windows 安装版、便携 EXE 与 Mac 版直接打开学校原页面登录，完成后回应用读取，**不需要到开发者工具复制 Cookie**。各业务的权限分别由学校决定。学业完成情况、创新领航讲座目前打开官方页面查看。[课表、成绩与登录步骤 →](docs/guide/campus.md)

## 图书馆：查到书，也查到去哪里拿

**在出发去图书馆前，先查这本书在哪、能不能借。无需登录。**

输入书名、作者或主题 → 查看书目 → 展开「查看馆藏」，得到每册书的**馆藏位置、索书号和在架状态**。检索支持翻页，也保留学校书目原页，实际借阅以馆方记录为准。

![真实馆藏查询：书目列表下展开馆藏位置、索书号和可供出借状态](docs/readme-campus.png)

*上图是实际查询得到的书目和馆藏信息。查到书之后，可以带着位置与索书号去找它。*

个人借阅记录、知网和万方也有入口，但会打开学校或数据库原页面；目前没有在应用内同步借阅、续借或检索论文。数据库访问权限以学校和数据库的实际授权为准。[图书馆使用说明 →](docs/guide/campus.md)

## 校园生活：场地时段、预约与宿舍电量

**准备自习、约同学运动，或者想查宿舍还剩多少度电，可以从这里开始。**

- **学习空间**：选场地与日期，看静音舱等空间的半小时空位和使用规则；选定后打开学校预约页办理。桌面版会在应用的学校窗口中打开原页面，查询空位不等于预约成功。
- **体育场馆**：选择学校返回的运动项目与日期，查询场地和可约时段，项目不限于羽毛球。应用内有「核对 → 确认提交」流程，**真实预约提交仍未验收**，请在官方页面核对结果。
- **自习提醒**：在学校完成预约后，手动登记地点和时间，导出日历文件并导入自己的日历，由日历在开始前 15 分钟提醒。
- **宿舍电量 · 测试中**：先配置学校的本机查询入口，在可直连的校内网络下，选校区、楼栋，填写房号和日期，查询剩余电量及累计用电、购电。单位是 **kWh（度）**，不充值、不查询人民币余额；真实房间尚未验收。
- **学院琴房 · 测试中**：有该系统权限的同学，可尝试读取琴房列表和自己的预约；尚无应用内预约、取消和开门功能。

学校登录、网络与使用权限由各服务决定；应用不定时抢位。[场地、电量与提醒的完整操作 →](docs/guide/campus.md)

## 课程笔记：从课堂记录到复习计划

**每门课一本书架。上课先记下来，下课把没弄懂的地方变成一件待办。**

![课程笔记真实界面：左侧课程书架，中间示例笔记，右侧页面大纲](docs/readme-notes.png)

*示例：给「线性代数」建一页课堂记录，用大纲定位「特征值与特征向量」，再把需要复习的内容加入待办。截图中的课程与笔记均为演示内容。*

1. **记录**：手动建课程或主题，用课堂记录、阅读／组会模板开篇；Markdown 书写、排版阅读和本页大纲都在同一个窗口。
2. **找回**：按标题和正文搜索；首页能继续最近写的那一页。自动保存到本机，误删可从回收站恢复，支持 Markdown / TXT 导入、单页导出与整本备份。
3. **去做**：选中一句话加入待办，设日期；点「返回笔记」找回原来的课堂上下文，改名或移动课程也能找回。关联待办开始 5 / 25 / 45 分钟或自定时长的专注，完成后自己确认任务。

**想和同学一起写？** 每门课可以绑定一份飞书 Docx 或 Wiki 文档，打开飞书原页共同编辑。自行安装、配置并授权 `lark-cli` 后，还能只读导入一份本机副本；这条接入仍在测试，不是双向同步，也不要求把本地笔记交给开发者。

[学习功能与备份指南 →](docs/guide/study.md)

## 桌宠与庭院：学习之后，有一点看得见的变化

**关掉主窗口，伙伴还可以留在桌面一角。** 点它打开菜单，聊天、摸头、喂食、陪玩或让它休息；拖动换位置，滚轮改大小，也能隐藏、置顶或换一位伙伴。桌面与庭院共用成长记录，每位伙伴的名字和成长分别保留。

| 原创伙伴 | 它的性格 | 可以看到的小动作 |
| :-- | :-- | :-- |
| **荔宝** | 热情、爱张罗，有点冒失，总想帮你一把 | 举起小牌，为你加油 |
| **栗栗** | 一本正经看守纸箱，完全不知道自己长得抽象 | 巡视纸箱，再认真坐进去 |
| **小白** | 从文山湖边来的白鹭，话不多，留意身边的小变化 | 低头理一理羽毛 |

伙伴会回应摸头、专注、播种、收获和建造，各有动作与情境台词。新存档共有五位伙伴，完整名册及粉丝角色说明见[伙伴指南](docs/guide/garden.md)。Windows 安装版、便携 EXE 与 Mac 预览版都有独立桌宠；浏览器轻量版只保留窗口里的伙伴。

![庭院真实界面：当前伙伴陪在湖畔农田旁](docs/readme-garden.png)

*庭院会按你的进度提示下一步：收成熟的作物、交伙伴委托，或准备下一处建设。*

### 专注、种植和小游戏，玩的是同一个庭院

**完成专注 → 领荔枝币与成长 → 买种子、种植 → 用收成交委托、建庭院 → 得到布置与收藏。**

- **专注有回报**：完成并领取后，每分钟得到 1 荔枝币和 1 点成长；做完待办也能给伙伴成长。
- **农田会生长**：种小萝卜、草莓、蓝莓和荔枝，浇水缩短等待，关掉应用后也继续长。收成能喂伙伴、交委托、出售，或留作建设材料。
- **建设真的看得见**：用收成和荔枝币建起湖畔野餐角、育苗架、灯径，布置会出现在庭院场景里；来访故事与委托还会留下纪念物。
- **2048 帮你备种**：棋子是种子、作物与丰收篮。当天实际合出 128 或以上，可领一次种子补给，优先补委托和下一项建设缺的作物，再回农田播种。也有自动续盘、悔一步和里程碑贴纸。
- **留张明信片**：把当前伙伴、校园背景与自己的庭院进度导出为一张 PNG，自己决定是否分享。

按自己的节奏专注、种菜，慢慢把庭院建起来。[庭院玩法与伙伴操作 →](docs/guide/garden.md)

## 校园网：连接与排查，放在同一页

支持教学区深澜和宿舍区 Dr.COM 的登录、注销，识别失败时可以手动选区。启动时最多自动认证一次，可关闭。

连不上时，查看**外网是否可达、校园认证是否确认在线、门户是否可访问**，再根据诊断里的区域、协议与代理线索排查。比如能打开网页，也不一定代表校园认证已经成功。

路由器、代理或 VPN 下的真实认证仍有待补齐的现场验收，不能保证所有网络环境都自动修好。校园网认证和学校业务登录彼此独立；应用内 WebVPN 页面也不是整机 VPN。[校园网连接与排查指南 →](docs/guide/network.md)

## 使用前了解这些边界

这是预发布项目。**公告与馆藏、本机笔记、待办、专注和庭院可以先用起来；学校个人业务仍在逐项验收。**

- **需要真实账号继续验证**：个人课表与在线成绩、全校课表与培养方案、真实房间电量、体育预约提交、学院琴房及飞书授权导入。查询入口或界面存在，不代表这些业务已经全部验收通过。
- **只打开原页面的功能**：学业完成、讲座记录、个人借阅、知网与万方。社区预约也在学校原页完成；没有自动选课、抢位或论文全文下载。
- **本机数据不会跨设备同步**：庭院与待办、课程笔记分开备份；飞书只读导入。笔记没有图片附件或公式排版。
- **平台范围**：Mac 是预览版，仍有真机验证项；没有手机版，Linux 只有校园网命令行。实验 VPN 不在默认发行版里。

## 安全与隐私

- **记录留在本机。** 庭院、待办与课程笔记保存在用户目录 `.szunet`，各自可导出；记录文件及导出备份未加密，请自行保管。
- **账号用系统安全存储。** Windows 用 DPAPI、macOS 用钥匙串；校园网命令行在 Linux 用 Secret Service，没有安全设施时拒绝保存。学校窗口的 Cookie 留在本机独立浏览器资料中，关窗不会清除，可主动删除登录状态。
- **没有遥测或统计埋点。** 校园查询请求相应学校服务；网络诊断会访问公共联网检测地址，手动检查更新会访问 GitHub。诊断报告可预览后复制，不自动上传。
- **认证协议有差别。** 教学区深澜使用 HTTPS；宿舍区 Dr.COM 使用学校现有的 HTTP 协议。项目不提供绕过计费或共享上网功能。

电量查询不借用教务 Cookie，房号和结果只留在当前界面内存。更多联网行为、备份与清除方式见[数据、隐私与安全](docs/guide/data-and-privacy.md)。

## 命令行 szunet

<details>
<summary><b>只想连接校园网，或在 Windows / macOS / Linux 上写脚本</b></summary>

从 [Releases](https://github.com/SzuDesktopTeam/szudesktop/releases) 下载对应系统的 `szunet` 单文件，将下面的命令名替换为实际文件名（macOS / Linux 通常加 `./`）：

```text
szunet config set    # 交互保存账号，密码不回显
szunet login         # 自动判断区域并登录
szunet status        # 查看当前区域与状态
szunet diag          # 诊断连接问题
szunet logout        # 注销
```

不要与官方客户端同时认证，也不要把密码写进共享脚本。全部参数与首次运行方法见[命令行指南](docs/guide/network.md)。

</details>
