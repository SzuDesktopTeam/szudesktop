# 架构决策记录（ADR）

这里记录的是**为什么这么设计**，不是功能说明。功能清单看 [README](../../README.md)，当前进度和待办看 [STATUS.md](../STATUS.md)。

> 这一批 8 篇是 **2026-11-06 追溯整理**的：把项目此前散在代码注释、STATUS.md 和发布说明里的设计取舍固化下来，方便查、也方便改。它们不是当时逐条实时写下的会议记录；每篇的「状态」栏都标了实施时间与整理日期。从这一批之后，新的重大决定应当在做之前或做的当下新增一篇。

## 什么时候该写

- 做了一个**反直觉**的选择（比如把网页编进后端二进制、拒绝做服务端）；
- 改变一条已有边界（比如从「只读」放开到「允许一种写操作」）；
- 引入或移除一项能力、依赖、平台，且代价会影响后面的人；
- 同一个问题被问了第二次，答案只存在于某个人脑子里。

小事不用写。每篇固定六段：状态 / 背景 / 备选方案 / 决定 / 代价与边界 / 怎么验证。**「代价」不能省**——只写好处不写代价的决策记录，等于广告。

状态用「已接受 / 已修订 / 已取代」。推翻旧决定时不要删旧篇，把它标成「已取代」并指向新编号，这样能看到判断是怎么变的。

## 目录

| 编号 | 主题 | 一句话 |
|---|---|---|
| [0001](0001-electron-shell-go-engine.md) | Electron 只做窗口，业务与页面都由 Go 引擎提供 | 一份内核支撑命令行、自带浏览器和桌面壳三种用法 |
| [0002](0002-loopback-service-credentials.md) | 本机服务用随机端口，每次启动生成凭据 | 回环地址不等于安全，别人扫到端口就能读笔记、借会话查成绩 |
| [0003](0003-user-supplied-session.md) | 学校会话由用户自己提供 | 不碰密码、不复刻登录，只保管和使用本人已登录的会话 |
| [0004](0004-local-only-data.md) | 不做服务端，个人数据只留在本机 | 隐私边界换来「不能同步、没有遥测」的代价 |
| [0005](0005-exclude-vpn-from-default-build.md) | 默认构建不含实验 VPN 模块 | 上游许可与 MIT 冲突，先把发布风险隔离，彻底移除另作决定 |
| [0006](0006-write-operations-boundary.md) | 写操作的边界与唯一例外 | 不做签到／选课／抢位；预约提交恢复后必须两步确认 |
| [0007](0007-multi-window-revision-lock.md) | 多窗口并发写与修订号乐观锁 | 冲突要报错，不能静默覆盖；平台语义差异是已知待修项 |
| [0008](0008-explicit-route-registration.md) | 路由显式逐条注册 | 让「每个接口都验凭据」变成能扫源码的断言，而不是靠自觉 |

## 护栏

`desktop/check-adr.mjs` 会检查编号连续、八篇齐备、每篇都有固定小节与状态行；`desktop/check_license_canonical.py` 守住 [ADR 0005](0005-exclude-vpn-from-default-build.md) 里那条「LICENSE 保持标准 MIT 全文」的约定。两者由 `desktop/run-checks.mjs` 自动发现。
