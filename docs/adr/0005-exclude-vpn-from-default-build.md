# ADR 0005：默认构建不含实验 VPN 模块

- 状态：已接受（beta0.5 起实施，2026-11-06 追溯整理；彻底移除仍待决定）
- 相关：`desktop/internal/ui/vpn_disabled.go`、`internal/vpn/`、`LICENSE`、`THIRD_PARTY_NOTICES.md`

## 背景

实验 VPN 模块移植自第三方实现。核对来源时发现：上游原版已撤回 AGPLv3，可用 fork 没有 LICENSE（法律上默认「保留所有权利」），与本项目 MIT 许可冲突；该厂商此前对同类校园客户端有过维权记录。把这个模块打进默认发行包，等于拿整个项目的分发许可去赌。

## 备选方案

| 方案 | 为什么不选 |
|---|---|
| 照常打包，当作没事 | 许可证冲突不会因为没人发现而消失；公开仓库 + 公开发布件，风险是确定的 |
| 整个项目改用 GPL | 会和已分发的其他 MIT 组件、字体许可、以及项目定位冲突，代价远大于实验功能 |
| 立刻从仓库彻底删除 | 会丢掉已有的调研与实验代码；这一步留作后续决定，但**不能拖着默认构建一起等** |
| **默认构建不含该模块，来源与授权状态写清楚** | 选中：先把发布风险与实验代码隔离，再决定要不要彻底拆出 |

## 决定

- 用构建标记隔离：`vpn_disabled.go` 带 `//go:build !campusvpn`，提供空实现；不带该标记时默认构建不含实验模块。
- `LICENSE` 只保留标准 MIT 全文，不对未核实代码作「独立实现」保证；来源、字体、渲染模块和待核事项统一放 `THIRD_PARTY_NOTICES.md`。
- 默认界面同步清理：不打包第三方游戏原型美术与 SVBold/SVThin 字体，改用自绘角色、CSS 场景与随包附 OFL 声明的开源字体。
- 拿不准的**默认不推**：内部规划、内网地址、凭据只放 gitignored 的 `.local-docs/`，推送前跑敏感词自查。

## 代价与边界

- 校外访问相关实验能力在正式发行版里不可用；代码仍在仓库中，风险只是被隔离，没有消失。
- 是否把 `internal/vpn/` 彻底拆到独立仓库或从历史中移除，仍是待决项；这一条 ADR 只管「默认构建不含」，不假装问题已解决。
- 教训写在这里，别再犯：抄代码前先查许可证——AGPL 有传染性、没有 LICENSE 不能抄、许可证也可能被撤回。

## 怎么验证

默认 `go build ./...` 产物不含相关路由；`desktop/check_licenses.py` 核对随包许可文件；`LICENSE` 保持可被识别的标准 MIT 全文；每次发版前的敏感词自查覆盖新增文件与 diff。
