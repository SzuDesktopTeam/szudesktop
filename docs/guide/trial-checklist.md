# 试用自查清单

谢谢你参加 szuDesktop 的试用。这一页列出几件可以自己检查的小事，每件 2–5 分钟。只挑和你情况相符的做就行，做不了的直接跳过；不需要懂代码。

试用用的是招募你的同学发给你的那个版本，版本号在「设置 → 关于与更新」里能看到，回报时顺手写上。

## 回报时请注意

- 只回报「一致」或「不一致」，以及界面上提示的原文。
- **不要发**：校园卡号、密码、Cookie、成绩数字、课表或成绩截图、IP 地址。
- 需要附材料时，用「设置 → 关于与更新 → 反馈与建议」里的诊断报告：先点开「诊断报告 · 先预览，再复制」看一遍，再点「复制诊断报告」。报告只列判区、门户能不能连上、各项学校服务返回了哪些字段，不含账号、卡号、密码、IP、Cookie、成绩、课表或公告内容。复制之后由你自己决定发给谁，应用不会自动上传。
- 按招募你的同学告诉你的方式交回，问卷、群或私信都可以。

## 1. 第一次打开的几分钟（所有人）

1. 装好后第一次打开，按引导走一遍。建议的路线是：选一位伙伴 → 回到首页点「开始 5 分钟」→ 专注结束后领取奖励 → 到「荔枝庭院 → 我的农田」收下第一颗萝卜。
2. 用 Windows 安装版的话，关掉主窗口，再试着把应用找回来（点桌面伙伴或托盘图标）；用 Mac 的话，点程序坞里的 szuDesktop 图标或屏幕顶部的菜单栏图标。

回报：哪一步不知道该点哪里，或者在一步上卡了超过一分钟；关掉主窗口后能不能自己找回来。

## 2. 校园网：登录、注销、重登各一次（在校园网里的同学，尤其是住宿舍的）

1. 在「校园网」页填校园卡号和统一身份认证密码，点「登录校园网」。
2. 点「注销连接」，这时外网应该断开。
3. 再登录一次。
4. 哪一步不对，就点「运行网络诊断」，再复制诊断报告一起交回。

回报：你在宿舍区还是教学区（教学楼、办公楼、图书馆），用的是网线还是 Wi-Fi；每一步是否成功，以及提示原文。

- 开着 Clash 之类的代理软件时，先关掉再测。诊断如果提示「代理软件接管了学校域名」，也请告诉我们。
- 不要和学校的官方客户端同时开，两者会互相踢下线。

## 3. 课表和成绩：和学校系统对照（本科生、有排课的研究生）

1. 在「学习书屋 → 我的课表」或「成绩与绩点」上方选好本科或研究生。
2. 按页面提示在学校原页面登录，再读取课表或成绩。
3. 打开学校的官方系统逐项对照：课表看课程名、周次、节次、教室；成绩看课程名、学分、成绩、绩点，以及一共有几门。
4. 读完后复制诊断报告：报告里只有「哪些字段出现了」，没有具体内容。

回报：「一致」，或者「哪一项不一致」，例如「教室一栏是空的」「比学校系统少两门课」。不要发具体的课程名和分数。

## 4. 专注结束时的通知（Windows 安装版）

1. 在「设置 → 桌面陪伴」打开「专注完成时提醒我」，关掉「勿扰」。
2. 到「学习书屋 → 专注与小事」，在「自定时长」里填 1，点「开始」，然后关掉主窗口。
3. 一分钟后，看屏幕右下角有没有弹出通知。没弹出的话，看看 Windows 的「专注助手」或「请勿打扰」是不是开着。

回报：弹出了，或者没弹出（以及系统的「请勿打扰」是否开着）。

## 5. 开机自动启动（Windows 安装版）

1. 在「设置 → 桌面陪伴」打开「登录 Windows 时启动」。
2. 注销 Windows 或重启电脑，再登录。
3. 看桌面伙伴和托盘图标有没有出现；主窗口应该不弹出来。
4. 测完不想保留的话，回到同一处关掉。

回报：启动了还是没启动；主窗口有没有自己弹出来。

## 6. 双屏和合盖睡眠（有外接屏或笔记本的同学）

- 把桌面伙伴拖到第二块屏幕上，再拔掉或关掉那块屏幕，看伙伴回到了哪里、还找不找得到。
- 合上笔记本睡一会儿再打开，看伙伴和应用是否正常。

回报：你做了什么、看到了什么。

## 7. 英文系统下的校历（Windows 显示语言是英文的同学）

打开「学习书屋 → 我的课表」，看上方的学期名称和「第几周」对不对，有没有报错。

回报：对或不对；有报错就写下原文。

## 8. 过了零点还开着应用（可选）

晚上开着应用过了零点，第二天看首页的日期、伙伴小屋里的「庭院小计划」是不是已经换成新的一天。

回报：换了，或者没换。

## 9. 用 Mac 的同学（macOS 预览版）

macOS 版是预览版，下面几件事还没在真机上验收过，你的回报很有用。每件都按平常用应用的方式做就行，做不了的跳过。

1. 从浏览器下载 DMG、拖进「应用程序」后第一次打开：按[下载、安装与更新](install.md)里的步骤放行，看能不能打开。
2. 开一次 1 分钟专注，然后关掉主窗口：第一次提醒时系统会问要不要允许通知，看允许以后有没有弹出通知。
3. 在「设置 → 桌面陪伴」打开「登录 Mac 时启动」，注销再登录，看桌面伙伴和菜单栏图标有没有出现、主窗口有没有自己弹出来。测完不想保留的话，回到同一处关掉。
4. 按住 Control 点按桌面伙伴、在触控板上双指滑动调大小、切到别的桌面或全屏应用，看伙伴是否正常。
5. 在校园网里打开应用时，系统有没有询问「本地网络」权限。

回报：你的 macOS 版本和芯片（Apple 芯片或 Intel），每一步是否正常，以及看到的提示原文。

## 10. 用了一周以后

- 这一周大概打开了几次？是什么让你打开，或者不想再打开？
- 伙伴升级觉得太快、太慢，还是刚好？庭院里有没有想做却做不了的事？
- 一周前写的课程笔记，现在还能很快找到吗？
- 有没有哪个地方让你觉得「不知道这是干什么的」？
