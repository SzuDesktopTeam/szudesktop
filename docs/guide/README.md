# 使用指南

这里是 szuDesktop · 荔枝庭院的详细使用说明，按第一次使用时大致会遇到的顺序排列；项目介绍、下载按钮和已知限制见[项目首页](../../README.md)。

szuDesktop 是学生自制的工具，与深圳大学官方无关。

## 阅读顺序

指南共 10 页：本页是目录，其余 9 页如下。只想先用起来，读前两页就够了。
