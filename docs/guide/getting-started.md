# 快速上手

这一页带你走完第一次打开 szuDesktop 后的几件事：选一位伙伴、专注 5 分钟、收下第一颗萝卜，需要时再连校园网。前三步都不需要学校账号，断网也能做。

还没安装的话，先看[下载、安装与更新](install.md)。用 Mac 的话，macOS 版目前是预览版，第一次打开要先按那一页的步骤放行。

## 第一次打开：欢迎引导

第一次打开时会弹出一张欢迎引导，简单说明数据存在哪、怎么退出、先做什么。它有三个出口：

- 「去认识我的伙伴 →」：直接去伙伴小屋。
- 「先专注 5 分钟」：马上开始 5 分钟专注，并打开「学习书屋 → 专注与小事」看计时（已经在专注时只打开这一页）。
- 「先随便逛逛」：关掉引导，留在首页。按 Esc 也能关掉。

引导只在第一次自动出现。之后想再看，点页面底部的「欢迎引导」；旁边的「使用指南 ↗」打开的就是这套文档。

在 Mac 上，关掉主窗口后桌面伙伴和屏幕顶部的菜单栏图标还在，点程序坞里的 szuDesktop 图标就能找回主窗口；要完全退出按 ⌘Q。

## 认识首页

主导航有六项：**今日、校园网、校园服务、荔枝庭院、学习书屋、设置**。首页就是「今日」；其他页面顶部的路径也从「今日」开始，点它就回到首页。

- 窗口够宽时，书桌入口和庭院风景左右并排；窗口较窄时上下排列。
- 欢迎区直接显示本机记录里的三个数字：还没完成的**待办小事**、**累计专注**分钟数、**等待收获**的成熟田块。点数字可以直接跳到对应页面。
- 最近写过的一页笔记和庭院的「下一步」建议挨在一起：可以接着写笔记，也可以先去做眼前那件小事。
- 再往下是「今天谁陪你？」伙伴栏、「我的小事」待办清单和「开始 5 分钟」专注卡片。

**第一天和之后不一样**：建档当天（关掉引导以后也一样），首页标题是「在荔园，过好每一天。」，主按钮是「开始 5 分钟」，「今天谁陪你？」伙伴栏默认展开。从第二天起，标题换成「欢迎回来，庭院在等你。」，主按钮换成「去我的书桌 →」，伙伴栏默认收起，点开就能看到全部伙伴。

## 第一步：选一位伙伴

进入「**荔枝庭院 → 伙伴小屋**」，点一张伙伴卡片就选好了；首页「今天谁陪你？」里点「换它陪我」也可以。用 Windows 安装版或 macOS 版时，桌面伙伴会同步切换。

新存档默认有五位伙伴：荔宝、栗栗、小白、Pingu 和 Skipper。旧存档里的阿青留在「老朋友」里。每位伙伴分别保存自己的名字和成长，随时可以换。它们的性格、动作和照料方法见[荔枝庭院与伙伴](garden.md)。

## 第二步：专注 5 分钟

1. 回到首页点「开始 5 分钟」，专注马上开始，页面顶部会显示剩余时间。
2. 时间到后，点顶部的「查看专注」，或首页「下一步」里的「领取专注收获」，在「**学习书屋 → 专注与小事**」点「完成并领取奖励」，得到 5 荔枝币和 5 点成长。

想让这次专注对应一件具体的事，可以先写一件小事：

1. 在首页的「我的小事」，或「学习书屋 → 专注与小事」里，写下一件想做的事，点「添加」。可以顺手定个日期，也可以留空。
2. 在「专注与小事」的专注卡片里，「这次想做什么？」选刚才那件小事，再点「5 分钟」。

专注的奖励是每完成并领取 1 分钟，得 1 荔枝币和 1 点成长。完成专注不会自动勾掉关联的待办，做完了记得自己勾上。更长的专注、待办的编辑和归档，见[学习：待办、专注、课程笔记与飞书](study.md)。

## 第三步：收下第一颗萝卜

新存档一开始有这些东西：

| 资源 | 数量 |
| :-- | :-- |
| 荔枝币 | 40 |
| 食物 | 3 份 |
| 萝卜种子 | 4 颗 |
| 草莓种子 | 2 颗 |
| 已经种好的萝卜 | 1 块田 |

首页的「下一步」会先提示「第一颗小萝卜快熟了」，点「去看看农田」；也可以直接进入「**荔枝庭院 → 我的农田**」，点那块种着萝卜的田：

- 萝卜约 1 分钟成熟，专注 5 分钟回来时早就熟了。
- 马上浇水，剩余时间缩短到原来的 75%，大约 45 秒就能收。
- 收获得到 2 个萝卜和 1 点成长。

作物离线时也会继续生长，成熟后不会枯萎，一直等你回来收。收过第一颗之后，「下一步」会换成平常的建议，比如交付伙伴委托或开始一项建设。

![湖畔农田：点一块田，在农具箱里种植、浇水或收获](../screenshot-farm-preview.png)

## 第四步：连上校园网（需要时）

1. 进入「**校园网**」页。已经能上外网时，登录表单收在「连接 / 更换账号」里，点开即可。人在校外时，「校园认证」一栏显示灰色的「外网正常；没有检测到校园网认证页面（不在校园网内时属正常）」，不用处理。
2. 填校园卡号和统一身份认证密码，点「登录校园网」。
3. 想下次不用再输，勾选「认证成功后记住账号密码」。只有认证成功后才会保存，密码输错不会覆盖已经存好的账号。
4. 连不上时点「运行网络诊断」，看问题卡在哪一步；结果旁边的「校园网指南 ↗」讲了各种结论该怎么处理。

校园网登录和学校业务（课表、成绩等）的登录是两件事，分别办理。判区、接入点编号和命令行用法见[校园网连接与命令行 szunet](network.md)。

## 需要学校服务时再登录

学院公告和官方校历不用登录就能看，常用的学校入口也集中在「校园服务」里。课表、成绩这类学校个人业务需要在学校原页面登录，而且还在测试，结果请以学校系统为准。详细步骤见[校园服务与学校登录](campus.md)。

## 设置在哪里

「设置」分四个分区，窗口较窄时分区按钮排成两列：

| 分区 | 里面有什么 |
| :-- | :-- |
| 风景与偏好 | 窗外的风景；个人展示里的昵称、学院（填全称，「学校公告」会直接显示这个学院的通知）、庭院光线（暖阳 / 暮色）和「开启动画（伙伴与庭院风景）」，改完点「保存设置」 |
| 桌面陪伴 | Windows 安装版和 macOS 版：专注完成时提醒我、勿扰（暂停专注通知）、显示桌面伙伴、伙伴保持置顶、启动时自动连接校园网、登录 Windows 时启动（Mac 上是「登录 Mac 时启动」），以及「桌面伙伴」卡片里的「伙伴大小」滑杆。便携版：「开机自启」卡片 |
| 存档与隐私 | 导出庭院与待办、备份课程笔记、从备份恢复；「账号隐私」卡片里的「删除已保存凭据」 |
| 关于与更新 | 版本与更新（更新渠道、检查更新）、反馈与建议（复制环境信息；默认折叠的诊断报告，先预览再复制）、关于荔枝庭院（各项功能的状态以 README 的功能表为准）、退出应用 |

![设置的四个分区](../screenshot-settings-system-preview.png)

桌面陪伴里的开关和检查更新怎么用，见[下载、安装与更新](install.md)；存档和备份见[数据、隐私与安全](data-and-privacy.md)。

## 限制

- 课表、成绩、安装版学校登录接回、应用内预约和学院琴房都还没有通过真实账号验收，可能读取失败或结果不完整。
- 校园网认证还在教学区和宿舍区现场验收中；连不上时先点「运行网络诊断」，再看[校园网连接与命令行 szunet](network.md)。
- 还没开展真实同学试用，庭院的成长节奏和长期内容会根据试用反馈调整。

当前进度见[开发状态](../STATUS.md#s1-1)。
