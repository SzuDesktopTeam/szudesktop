# 伙伴与课堂笔记：5 人、1 周试用

> **浏览器方案，不作为 1.0 门槛。** 这是 2026-10-01 准备的浏览器试用候选，需要现有 Node.js。1.0 前的首轮试用改用原生安装包，按[试用自查清单](trial-checklist.md)和[首轮试用观察表](trial-observation.md)进行（维护者 2026-10-05 的决定，见[开发状态](../STATUS.md#s73)）。本页保留，供以后单独比较浏览器方案时参考。

这是尚未发布的本机试用候选，只看两件事：伙伴的摸头回应，以及上课时新开一页、下次继续写。是否有吸引力、是否值得安装，都还没有真实试用证据。

## 开始前

维护者先记录每人 S01–S05 的回答，再展示演示，避免把看完演示的好感当成下载意愿。名单、联系方式自行保管，不放进公开仓库。

1. 平时用什么记课堂重点？电脑端有多少次真实记笔记机会？
2. 只看到项目介绍时，愿不愿意下载：愿意 / 犹豫 / 不愿意？最主要原因是什么？
3. 能否接受当前未签名安装包的安全提示？能否接受本浏览器候选需要现有 Node.js？两项分别回答，不合并成“安装成功”。

本候选是浏览器前端加已发布 beta0.9.5 Go 引擎，不是新 Windows 安装包。原生候选编译、签名和系统行为另行验收。若同学没有现成 Node.js，不要求为测试安装软件，记录为试用门槛，由维护者在适配好环境的独立设备上观察首次体验；这种情况不能算一周本人留存。

## 给参与者的快速开始

需要 Windows x64 和已安装的 Node.js 22 或更高版本。拿到试用 ZIP 后，先完整解压到自己可以写入的固定文件夹，不要直接在压缩包内运行。

1. 双击解压目录里的 `START.cmd`，保持打开的终端窗口。
2. 把终端中 `Trial preview:` 后面的完整链接复制到浏览器。地址以 `http://127.0.0.1:` 开头，只供这台电脑访问；不要把完整链接发给别人。
3. 在浏览器完成下方“第一次”的两项任务。不要输入学校账号，不需要登录或连接飞书。
4. 写完等笔记状态显示“已保存到本机”，再离开或退出。从“设置 → 关于与更新”选择退出应用；也可以在自己的试用终端按 Ctrl+C。正常退出后再关闭终端窗口。
5. 下次仍在同一文件夹运行 `START.cmd` 并打开终端链接。不要清空 `trial-data`、删入口记录或在运行时搬动文件夹；先导出整本笔记备份再移动或删除。

没有出现链接、提示端口占用或等待超时时，先保留报错与原目录，向维护者反馈，不要关闭不认识的进程或改系统设置。没有现成 Node.js 时，请记录环境不适配，不要为了这轮试用安装软件。

## 第一次，尽量不提示

给同学试用链接，让其自行完成下面两件事。观察者只有遇到安全边界或明确求助时才打断。

- 找到伙伴、摸摸头。能否看见动作、理解回应？没有成功或需要指路，也照实记录。
- 记下一个自己的课堂重点，再回到“今日”，找到它继续写。观察者记录每一步耗时、点击数、求助次数；不要收集正文。

在书屋里可新建自己的课程。此后首页“新开课堂记录”沿用当前课程，显示归属，带课堂模板并直接进入正文；“继续写笔记”回到最近编辑的未删除笔记。两者都不需要学校账号。

## 接下来 7 天

只在有真实需求时打开，不要求每天打卡、不用每天提醒，避免把配合测试误算成留存。每天用表记一次“是否有记笔记机会、是否主动打开、完成了什么、原工具是什么、为何回来或没回来”。没有上课/没带电脑与有需求但没选它分开记录。第 7 天再回答：愿意保留吗？最有用的一件事？可以删掉的一件事？和原工具相比具体少了哪一步？

不要提交密码、Cookie、课表、成绩、笔记正文、截图里的个人信息。反馈表只写匿名编号与操作结果；没有自动上传或遥测，表由同学本人选择交回。反馈目的地由维护者指定。本次没有联系同学或发送邀请。

## 怎么判断这一轮

先看个体记录，不把 5 人样本包装成市场结论：

- 安装意愿：展示前愿意/犹豫/不愿意各几人；信任、环境和功能原因分别记。
- 首次体验：独立完成摸头、创建和续写各几人；保存失败、找不到、需要解释分别记。
- 一周价值：有使用机会的同学中，谁在至少 3 个不同日期主动回来，具体为了什么；只有围观伙伴与真正用笔记分开记。

继续推广的工作标准：没有数据丢失或安全问题，至少 4 人独立完成首次核心操作；至少 3 人有真实使用机会且在 3 个不同日期主动使用，能说出一个比原工具方便的具体步骤。达不到就围绕主要阻碍改下一轮，不补新功能。机会不足则结论为“样本不足”，不判定成功或失败。这些是本轮工作标准，不是正式发布的充分条件。

## 隔离和退出

候选只访问自己的试用目录，不读取已有 .szunet，不调用学校服务，不保存校园账号。待笔记状态显示“已保存到本机”后，可用设置里的退出应用，或在终端按 Ctrl+C。每次用同一个试用目录才能继续上次记录。请先导出“整本备份”，再移动或删除候选目录。

教学区/宿舍区登录闭环、真实安装升级/卸载、通知、自启动、钥匙串和长期资源占用没有因这轮浏览器体验验证而通过。
