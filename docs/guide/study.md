# 学习：待办、专注、课程笔记与飞书

这一页介绍「学习书屋」里的待办、专注和课程笔记，以及怎样把课程的共享文档交给飞书。这些功能都不需要学校账号，断网也能用。

## 功能状态

| 功能 | 状态 | 说明 |
| :-- | :-- | :-- |
| 待办与专注 | ✅ 可用 | 待办可以编辑、定日期、归档和恢复；专注可选 5 / 25 / 45 分钟或自定 1–120 分钟 |
| 课程笔记 | ✅ 可用 | 本机文本笔记：手动建课、模板、搜索、Markdown、大纲、回收站、导入导出与整本备份 |
| 飞书课程文档 | 🧪 测试中 | 打开飞书原页面共同编辑，用你自己的 lark-cli 只读导入本机副本；不是双向同步 |
| 专注完成提醒 | 🧪 测试中 | 仅 Windows 安装版：专注完成时提醒，可以开勿扰 |

图例：✅ 可用 · 🟡 部分可用 · 🧪 测试中 · — 不支持。各项的缺口见页末「限制」。

## 学习书屋在哪

顶部导航的「学习书屋」分为四个分区：课程笔记、专注与小事、我的课表、成绩与绩点。刷新页面或前进后退时，会回到你当时所在的分区。

课表和成绩需要学校登录，见 [校园服务与学校登录](campus.md)。

## 待办

「专注与小事」里的「我的小事」是你的待办清单。

- 写下一件小事，可以给它定一个日期。
- 可以编辑文字、改日期、标记完成。完成的小事可以归档，需要时再从归档里恢复。
- 清单分为待完成、已完成、归档三栏。
- 每天首次完成的前 5 件小事，各给当前伙伴 2 点成长；编辑后反复勾选不会重复给。

## 专注

1. 在「这次想做什么？」里选一件待办，或者选「不关联待办」。
2. 点 5、25 或 45 分钟；也可以在「自定时长」里填 1–120 分钟，再点「开始」。
3. 时间到了点「完成并领取奖励」：每完成 1 分钟，获得 1 荔枝币和 1 点成长。

- 专注不会自动勾掉关联的待办，完成与否由你决定。
- 中途点「结束本次专注」会再确认一次；提前结束不会获得本次奖励。
- 计时不监测你的学习行为。
- 完成并领取的专注会记进「这一周，慢慢积累」的最近 7 天回顾，最多保留最近 365 条记录。

[查看专注与小事的界面](../screenshot-study-preview.png)（截图来自旧版界面，顶部导航名称与当前版本不同）

### 专注完成提醒（Windows 安装版）

- 「设置 → 桌面陪伴 → 专注完成时提醒我」：主窗口隐藏时也会提醒；完全退出应用后不再提醒。
- 想安静一会儿，可以开「勿扰」：「设置 → 桌面陪伴」里的「勿扰」和托盘菜单里的「勿扰（暂停专注提醒）」是同一个开关。勿扰只暂停专注通知，不改变计时、互动或奖励。

## 课程笔记

### 打开书屋

- 首页点「去书屋写笔记」，或进入「学习书屋 → 课程笔记」。
- 首页场景里的书屋入口和最近笔记卡片，也通向同一个本机笔记本。
- 首页的「继续写笔记」会定位到最近修改且未删除的那一页，同时清除之前的搜索和回收站筛选。

### 建课与写一页

- 在「我的课程书架」点「+ 新建课程 / 主题」。课程完全手动建立，不需要学校登录；课程之后可以改名。
- 点「+ 写一页」新建一页。还没有打开笔记时，页面上可以直接选一种模板开始：空白笔记、课堂记录、阅读 / 组会。
- 每一页可以在「书写」和「阅读」之间切换：书写时用 Markdown，阅读时显示排好的版式。
- 点「专心书写」突出正文，写完点「回到课程书架」。
- 笔记页上可以直接调整这一页属于哪门课程。

### 本页大纲

可折叠的「本页大纲」会提取正文里的标题。书写或阅读时点一下，就跳到对应的标题。代码块里的 `#` 不会被当成标题。

### 搜索

书架上的搜索框同时查找标题和正文，会显示找到几页，并提供「清除搜索」。当前打开的这一页不符合筛选时，正文保持不变，另给出「回到当前页」的入口。书架很长时，书架和笔记列表各自滚动。

### 回收站

- 点「移到回收站」后，正文仍完整保留，可以「恢复这页」回到原来的课程。
- 在回收站里可以「永久删除」单页，也可以清空回收站。永久删除后无法恢复，需要留底的话先导出。

### 从笔记回到日常

- 在正文里选中一句话，点「加入学习待办」。
- 在正文工具栏点「开始 25 分钟专注」，沿用上面的专注规则。
- 写了多少字、导入了什么内容，都不会直接变成庭院奖励。

### 自动保存

- 笔记自动保存到本机，页面上能看到保存状态。
- 保存过程中再次点击操作，会提示正在等待什么。
- 两个窗口同时改同一本笔记时，不会静默覆盖：当前草稿会保留，页面提示先「导出当前草稿备份」，再「读取最新版本」。
- 笔记文件损坏时，会自动恢复到上一次成功保存的版本。
- 正常退出安装版前会先保存笔记。保存失败时默认回到主窗口，可以重试或导出；只有明确选择「放弃未保存修改并退出」，才会继续退出。

### 导入、导出与备份

| 想做什么 | 在哪里 |
| :-- | :-- |
| 导入 Markdown / TXT，成为一页新笔记 | 课程书架「导入与备份 → 导入 Markdown / TXT」 |
| 把单页导出为 `.md` | 笔记页的「导出 .md」 |
| 导出整本笔记本（课程、笔记、当前草稿和回收站）为 JSON | 课程书架「导入与备份 → 导出整本备份」，或「设置 → 存档与隐私 → 备份课程笔记」 |
| 从整本备份恢复 | 课程书架「导入与备份 → 恢复整本备份」；恢复前会提示将替换本机笔记本，庭院存档不受影响 |

- 整本笔记本的上限是 8 MiB，导入的单个文件也要在 8 MiB 以内。
- 笔记保存在本机的 `notebook-v1.json`，是**明文、未加密**的文件，和庭院存档分开。庭院备份不包含笔记，换电脑时两份要分别导出。详见 [数据、隐私与安全](data-and-privacy.md)。

## 飞书课程文档

个人笔记留在本机；想和同学一起写，可以把这门课的共享文档交给飞书。

### 绑定并打开共享文档

1. 在课程名称旁展开「课程设置与共享文档」，填入一份你有权限的飞书 Docx 或 Wiki 文档链接（HTTPS）。每门课绑定一份。
2. 点「打开共享文档」：安装版在独立窗口打开飞书原页面，便携版和浏览器模式用浏览器打开。
3. 共同编辑、评论和权限都由飞书处理。

### 读入一份本机副本（可选）

- 需要你自己安装并配置好 `lark-cli`。应用会调用它，以你自己的授权身份读取所选文档，然后在本机新建一页带来源链接的笔记，按钮是「导入到本机新笔记」。
- 「连接飞书账号」提供飞书官方的只读授权入口（文档与知识库只读）；「检查连接」查看当前状态。
- 没有配置 CLI，也可以打开共享原文。
- CLI 没安装、没配置、权限不足或返回异常时，会明确说明原因，不会显示成空文档；文档过大时也会明确提示。

### 这不是双向同步

- 本机副本的修改不会回写飞书；飞书原文之后的修改，也不会自动覆盖本机笔记。
- 应用不会用开发者的共享账号代替你访问飞书。

### 两套授权互不相通

- 飞书窗口里的登录不等于 CLI 已授权；CLI 授权也不会让窗口自动登录。
- 窗口的登录状态只在本次运行期间保留，完整退出后清除，也不会接回本地笔记服务。
- CLI 凭据由你自己的 `lark-cli` 管理，应用里没有打包组织的 App Secret。

## 限制

- 课程笔记只支持文本：还没有 AI 整理、PDF / 课件解析、图片附件、公式排版、录音或云端同步。正文里的原始 HTML 按普通文字显示，远程图片显示为链接。
- 退出前先保存只覆盖正常退出；断电、强制结束进程或所有关机情形没有逐一验收。
- 飞书：项目专属的组织加入入口还没有配置，也没有邀请同学、建组织或修改文档权限的功能。真实飞书登录、受权限约束的文档导入和多人协作还在验收。
- 专注完成的系统通知是否真的弹出，还没有实测。
- 还没有开展真实同学试用。
