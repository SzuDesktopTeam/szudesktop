# 分发与首轮试用文案

给组织分发和试用的维护者用：一句话定位、按当下痛点直接发的话术、视频与分享图文案，以及 10 分钟小忙的通用文案。观察怎么记见[首轮试用观察表](trial-observation.md)。

## 一句话介绍

> szuDesktop：校园网连不上时一次定位卡在哪一段，17 个学院的公告、馆藏位置与校历课表收在同一个桌面窗口。免安装、免登录就能开始用；记录只存在你自己的电脑上，源码公开、MIT 许可。

当面观察时只给这一句和下载地址，不演示、不讲界面。

## 群里直接发

> 校园网又连不上？我这有个不用登录的小工具，能一次查清是外网、校园认证还是门户断了。便携版双击就能用，你装一下试试，卡在哪儿告诉我一声。

同一个工具，按对方此刻正在遇到的麻烦换第一句：

| 对方正在做的事 | 直接发这一句 |
| :-- | :-- |
| 群里问「网怎么又断了」 | 我这个能一次定位是外网、认证还是门户断了，双击就能跑，不用装、不用登录。 |
| 开学、换了电脑 | 装一次就能连校园网、看通知、查馆藏；便携版双击直接用，不用管理员权限。 |
| 翻学院网站找通知 | 17 个学院的通知在一个窗口里搜全文，正文和附件就地展开，不用挨个开网站。 |
| 去图书馆前确认书在不在 | 搜书名就看馆藏位置、索书号和在架状态，不用登录。 |

GitHub 打不开时，把便携版 EXE 和同名的 `.sha256` 一起发到群里，核对方式见[下载、安装与更新](install.md)。

## 10 分钟小忙（通用文案）

> 帮我一个 10 分钟的小忙：装一下 szuDesktop，随便点一点，我在旁边看着、不插话。
>
> 用你自己的 Windows 电脑就行，不需要学校账号，不用连校园网，也不用填表。
>
> 我想看的就三件事：装不装得上、第一下你会点哪里、关掉窗口之后找不找得回来。
>
> 第一次打开时系统可能拦一下，按[放行步骤](install.md)走就行；这一步我单独记，不算你卡住。

## 顺带能覆盖的几类场景（可选）

下面几类能顺手多验一点学校业务，都是可选的，不影响首轮五步的计入。对应[试用自查清单](trial-checklist.md)里的一项，只回报「一致」或「哪一项不一致」，不用发内容。

| 想找的人 | 加一句 | 自查清单 |
| :-- | :-- | :-- |
| 本科生 | 如果你愿意，可以顺手对照课表和成绩是否和学校系统一致。 | 第 3 项 |
| 住宿舍的同学 | 如果你住宿舍，可以顺手试一次宿舍区校园网的登录、注销和重登，告诉我每一步的提示原文。 | 第 2 项 |
| 有排课的研究生 | 如果你这学期有排课，可以顺手对照研究生课表的周次、节次和教室。 | 第 3 项 |
| Windows 显示语言是英文的同学 | 如果你的 Windows 是英文界面，帮忙看一眼校历和「第几周」显示得对不对。 | 第 7 项 |
| 用双屏、或笔记本常合盖睡眠的同学 | 如果你常接外接屏或合盖睡眠，帮忙看看桌面伙伴的位置和睡醒后的样子。 | 第 6 项 |

用 Mac 的同学一样欢迎，观察记录同样有用；5 人门槛按 Windows 首次上手的记录统计。

## 视频标题与简介

被动搜索会持续带来新的人。已有的一分钟视频按别人真会搜的词起标题：

- 标题：`深大 校园网 连不上 怎么查` ／ `深大 通知 不用挨个翻学院网站`
- 简介第一句：`校园网断在哪一段，一次查清；便携版双击就能用，不用装、不用登录。`
- 简介结尾三行：`数据不出本机` · `无服务端、无账号` · `源码公开 MIT`，下面放项目主页与便携版下载链接。

## 分享图上的三句话

图只负责让人 30 秒决定要不要点开，把最强的一条放最大：

1. **校园网连不上，一次定位卡在哪一段**
2. **17 个学院通知 + 馆藏位置 + 校历课表，一个窗口**
3. **免安装、免登录；数据只留这台电脑，源码公开 MIT**

## 分发顺序

1. 便携 EXE 与同名 `.sha256` 放在手边，任何渠道都能立刻把文件递出去。
2. 三个 contributor 各装一次，各留一条首次上手记录。
3. 有人问「网怎么又断了」时，用上表对应的那句话加文件。
4. 视频按搜索词改好标题与简介，让开学、换设备、断网高峰持续被搜到。
5. 反馈走应用内「设置 → 关于与更新 → 反馈与建议」，诊断报告可先预览再复制。

## 发出前确认

- 版本号和下载方式按当时的发布页写，不放占位链接。
- 名单和联系方式由维护者自己保管，不放进仓库。
- 报名的人用哪种电脑，记进观察表的「平台与安装形态」。
