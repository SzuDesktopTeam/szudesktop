# 首轮试用招募文案（草稿）

这一页给招募首轮试用同学的维护者用：一句话介绍、通用招募文案、想特别找的几类同学各加一句，以及发出前的检查。都是草稿，发之前按当时的版本号和下载方式改。观察怎么做、记什么，见[首轮试用观察表](trial-observation.md)。

## 一句话介绍

> szuDesktop · 荔枝庭院：深大学生自制的桌面小庭院（与学校官方无关）。选一位像素伙伴陪你专注，顺手记课堂笔记、看学院公告和校历；不用学校账号也能用，数据只存在你自己的电脑上。

当面观察时，给同学的介绍只有这一句和下载地址，不另外演示。

## 通用招募文案

> 想找 5 位同学帮忙试用一个桌面小应用：szuDesktop · 荔枝庭院（深大学生自制，与学校官方无关）。
>
> 它是放在电脑桌面上的一个小庭院：选一位像素伙伴陪你专注，专注完收一点小奖励；也可以按课程记笔记，看学院公告和校历。
>
> 需要你做的：
>
> - 带上自己的电脑（Windows 10 / 11，或 Mac），当面大约 20–30 分钟：你自己下载、安装、随便用一用，我在旁边看，尽量不插话。
> - 之后一周照平常的习惯用，想用再打开，不用打卡；一周后花 5 分钟聊聊感受。
>
> 我们不收集你的账号、密码、成绩和课表，试用也不需要登录学校系统。应用没有统计埋点，数据只存在你的电脑上。
>
> 安装包目前没有数字签名，下载和第一次打开时浏览器或系统会拦一下，这是预期内的。
>
> 有兴趣的话回复我：用的是 Windows 还是 Mac，大概哪天方便。

## 想特别找的几类同学

首轮最好凑齐下面几类。招募时在通用文案后面加对应的一句；这些都是可选的顺带检查，对应[试用自查清单](trial-checklist.md)里的一项，不影响首分钟流程的观察。

| 想找的同学 | 招募时加一句 | 自查清单 |
| :-- | :-- | :-- |
| 本科生 | 如果你愿意，可以顺手对照课表和成绩是否和学校系统一致，只告诉我「一致」或「哪一项不一致」，不用给我看内容。 | 第 3 项 |
| 住宿舍的同学 | 如果你住宿舍，可以顺手试一次宿舍区校园网的登录、注销和重登，告诉我每一步的提示原文；这部分我们自己测不到。 | 第 2 项 |
| 有排课的研究生 | 如果你这学期有排课，可以顺手对照研究生课表的周次、节次和教室，同样只说一致不一致。 | 第 3 项 |
| Windows 显示语言是英文的同学 | 如果你的 Windows 是英文界面，帮忙看一眼校历和「第几周」显示得对不对。 | 第 7 项 |
| 用双屏、或笔记本常合盖睡眠的同学 | 如果你常接外接屏或合盖睡眠，帮忙看看桌面伙伴的位置和睡醒后的样子。 | 第 6 项 |

用 Mac 的同学一样欢迎。macOS 版是预览版，在 macOS 首次放行的真机验收通过之前，Mac 同学的结果不计入 5 人门槛，但观察记录照样有用。

- 招募海报、分享图、演示动图和社交预览只用原创伙伴：荔宝、栗栗、小白（维护者 2026-10-05 的决定）。Pingu 和 Skipper 是项目自己画的粉丝形象，不放进宣传物料；应用里的伙伴阵容不变。
- 截图用全新存档，不带个人信息（名字、课程、学院、成绩）。

## 发出前检查

- 版本号和下载方式按当时的发布页写，不放占位链接；还没定下来的渠道（比如不需要 GitHub 账号的反馈方式、国内备用下载）不写进去。
- 不写「官方」「学校出品」这类说法；课表、成绩、学校登录这类功能还在测试，不承诺一定能用。
- 名单和联系方式由维护者自己保管，不放进仓库。
- 报名的同学用的是哪种电脑，记进观察表的「平台与安装形态」。
