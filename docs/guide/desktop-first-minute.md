# 桌面首分钟学习与重载

beta0.9.6 将首分钟学习改进放入真实桌面应用：从首页「课堂记录」创建模板笔记，从「继续最近笔记」恢复最近编辑的一页。笔记自动保存在本机；离开笔记页、退出应用前会等待保存完成。保存失败时保留草稿，请先重试或导出笔记备份。

在设置页点击「保存并重新打开」，应用先保存课程笔记与 2048 进度，再重新读取工作区。这个按钮重新载入主窗口页面，不会重启桌面引擎、关闭学校登录窗口或清空存档。保存失败时页面保留，并显示错误；排除磁盘或存档冲突问题后可以重试。

欢迎引导会等待存档成功后关闭，避免刚关闭引导就摸头时遇到修订冲突；重复提交不会重复写入。遇到外部修改造成的冲突时，应用保留并提示当前状态，不将旧页面覆盖到新存档。

## 交付验证范围

- JavaScript、Python 和 Go 检查覆盖引导并发、恢复并发、失败保留草稿、重载等待与重复点击。
- 原生 Electron 冒烟在隔离配置中创建合成课堂笔记，立即离开页面，再从设置页重载并恢复最近笔记，同时核对真实 Go API 数据。Windows 安装/升级/卸载与 macOS DMG 冒烟由仓库 CI 在专用 runner 上执行，结果以对应提交的 Actions 记录为准。
- 此前的 45 分钟记录是浏览器测试版测试，不能作为安装版长时间验收。
- 真实校园登录、校园网认证、睡眠恢复、多屏日常使用以及真实用户长时间验收仍待完成。生产代码签名与 macOS 公证仍未完成；本次只发布预发布版。
