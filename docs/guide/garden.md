# 荔枝庭院与伙伴

这一页介绍荔枝庭院怎么玩：选一位伙伴、种菜收成、完成委托、在湖边建设，还有 Windows 安装版里常驻桌面的伙伴和几套可选风景。庭院不需要学校账号，断网也能玩。

## 功能状态

| 功能 | 状态 | 说明 |
| :-- | :-- | :-- |
| 荔枝庭院 | ✅ 可用 | 照料伙伴、种植四种作物、伙伴小桌 2048、委托、集市、庭院建设、来访故事和明信片，全部在本机离线运行 |
| 桌面伙伴 | ✅ 可用 | 仅 Windows 安装版：透明窗口、菜单照料、滚轮缩放、拖动、隐藏与托盘 |

## 庭院怎么转起来

庭院的循环是：**专注与陪伴 → 备种和种植 → 收成 → 伙伴委托与庭院建设 → 场景布置和收藏**。整个庭院共用同一份种子、收成、荔枝币和伙伴成长，没有第二套货币；也没有充值、现金交易、排行榜或实时对战。

「荔枝庭院」页分为五个区：

| 分区 | 在这里做什么 |
| :-- | :-- |
| 伙伴小屋 | 照料伙伴、查看成长、领取庭院小计划、切换伙伴、看收藏 |
| 我的农田 | 播种、浇水、收获、开垦新田 |
| 庭院集市 | 伙伴委托、种子铺、出售多余的收成、买食物和小屋装饰 |
| 伙伴小桌 | 2048 与每日备种礼 |
| 回忆与建设 | 庭院建设、来访小故事、作物图鉴和纪念章 |

首页和庭院会根据你的真实进度提示「下一步」能做的一件事，直接带你去成熟的田块、可以交付的委托、可以开始的建设、种子铺或专注。正在生长的作物也计入准备进度。新存档在收下第一份收成之前，「下一步」先提示建档时种下的那颗萝卜。

新存档一开始有什么、第一段体验怎么走，见 [快速上手](getting-started.md)。

## 动作与台词

- **动作**：六种伙伴各有 18 组动作、每组 6 帧，共 648 帧独立像素画。除了发呆、散步、睡觉、摸头、吃点心这些日常动作，还有浇水、抱回收成、递礼物、搭建、思考和拿手动作。
- **在哪里看**：在伙伴小屋展开「它的小动作」，按日常、互动、庭院三组逐组播放；展开「细看这组小动作」可以查看每一帧。主窗口和桌面伙伴用的是同一个播放器。
- **静态形象**：另有 30 张静态形象，用于「减少动态效果」和导出明信片。
- **台词**：共 1,656 句，覆盖 23 类情境，每只伙伴每类 12 句，按各自进度轮换并存档。除了摸头、喂食、专注、收获这些日常，播种、浇水、交付委托、建造、领取种子补给、开始专注和拿手动作也都有对应的回应。栗栗一本正经地巡视纸箱，Pingu 会误会小东西，Skipper 连休息都当成后勤安排。台词按情境出现，不会频繁打扰。
- **农田旁的陪伴**：当前伙伴会出现在农田旁边。播种、浇水、收获后，能当场看到它的动作和回应，不必回小屋。
- **拿手动作**：伙伴小屋里每位伙伴都有自己的拿手动作按钮，比如荔宝的「给你加个油」、Pingu 的「Noot 一下」。拿手动作免费，不消耗资源，也不增加成长或亲密度。「聊两句」同样不消耗体力。
- **不打扰休息**：睡眠和专注优先，拿手动作不会打断它们。开启「减少动态效果」时使用静态形象。

## 桌面伙伴（Windows 安装版）

安装版有一个独立的透明窗口，关掉主窗口后伙伴仍留在桌面上。便携版保留窗口里的庭院养成，没有独立的桌面伙伴和托盘。

- **点一下打开菜单**：左键或右键点击伙伴。菜单顶部显示「名字 · Lv.等级」和「饱腹 · 心情 · 精力」；下面可以「聊两句」「摸摸头」「喂食（剩余 N 份）」「陪它玩」「让它睡一会」（睡着时变成「叫醒伙伴」），以及「切换伙伴」，旧伙伴后面标着「· 老朋友」。照料沿用庭院规则，记在同一份本机存档里；食物不足、精力不足或还在冷却时，会提示原因。
- **去别的页面**：菜单里的「看看庭院」「照看农田」「学习与专注」「打开主窗口」会打开对应页面。
- **调整大小**：鼠标停在伙伴上滚动滚轮，每次调整 10 个百分点，范围 40%–200%。也可以用菜单里的「宠物大小」（缩小一点、放大一点、小 60%、中 100%、大 150%、恢复默认大小）、托盘「宠物大小」里的小 / 中 / 大三档，或者「设置 → 桌面陪伴」的「桌面伙伴」卡片里的「伙伴大小」滑杆。
- **移动位置**：按住伙伴拖到喜欢的位置。大小和位置在重启后恢复。伙伴周围的透明区域可以点穿，点击会落到下面的窗口。
- **隐藏与置顶**：菜单里有「宠物置顶」「隐藏宠物」，托盘里有「隐藏宠物 / 显示宠物」「宠物置顶」；「设置 → 桌面陪伴」里对应的开关叫「显示桌面伙伴」和「伙伴保持置顶」（菜单和托盘还沿用「宠物」的旧叫法，指的是同一个桌面伙伴）。隐藏后可以从托盘重新显示，这些选择重启后保留。
- **托盘**：单击托盘图标打开主窗口。托盘菜单还有「勿扰（暂停专注提醒）」和「退出」；勿扰的作用见 [学习](study.md)。
- **退出**：菜单里的「退出应用」或托盘的「退出」会完整退出应用。其他退出方式见 [下载、安装与更新](install.md)。
- **和设置同步**：设置保存成功后，动画开关会立即同步到桌面伙伴；保存失败时伙伴不会提前改变。用自定义时长开始专注时，桌面伙伴也会立即同步。

## 照料与成长

| 做什么 | 得到什么 |
| :-- | :-- |
| 完成并领取 1 分钟专注 | 1 荔枝币 + 1 成长 |
| 摸头（每只伙伴每天前 3 次，间隔 10 秒） | 每次 2 成长、3 亲密度；之后仍可以互动 |
| 首次完成一件小事（每天最多 5 件） | 每件 2 成长 |
| 收获作物 | 按作物给成长，见下方作物表 |
| 交付伙伴委托 | 提出委托的伙伴成长 +5、亲密度 +3 |
| 领取伙伴小桌的每日备种礼 | 当前伙伴成长 +3、亲密度 +2、心情 +10 |

- 每 50 点成长升一级，最高 20 级。
- 伙伴升到 2 级解锁蓝莓种子，3 级解锁荔枝种子。已解锁的作物不会因为换伙伴而重新锁上。
- 亲密度和心情的上限都是 100。
- 喂食消耗一份食物，每份补充 30 点饱食；也可以把收成当作点心喂给伙伴，作物点心不消耗普通食物。
- 休息每小时恢复 30 点精力。离开几天，伙伴也不会死亡。
- 伙伴小屋的「庭院小计划」每天有四个小目标：陪伴伙伴 3 次、种下一颗种子、收获一块农田、完成一次专注，达成后分别领取 15、10、15、25 荔枝币。漏掉一天也没关系，没有连续签到要求。

## 农田与作物

湖畔小菜园是一幅原创像素场景，共有六块农田：一开始开放三块，另外三块可以用荔枝币开垦，依次 60、90、120 币。点选田块后，在工具面板里选种子、种植、浇水或收获。田块会分别显示成熟、生长中、已浇水和未开垦；窗口较窄时，农田排成两列。

| 作物 | 生长时间 | 种子价 | 一次收获 | 每个售价 | 收获成长 |
| :-- | --: | --: | --: | --: | --: |
| 小萝卜 | 1 分钟 | 4 币 | 2 个 | 3 币 | 1 |
| 草莓 | 5 分钟 | 12 币 | 2 个 | 12 币 | 5 |
| 蓝莓 | 20 分钟 | 24 币 | 2 个 | 38 币 | 20 |
| 荔枝 | 60 分钟 | 40 币 | 3 个 | 70 币 | 60 |

- 浇水把剩余生长时间缩短到 75%，不额外给成长。
- 离线时作物照样生长，也不会枯萎。
- 收获和奖励会显示实际到账的数量。作物图鉴只点亮你亲手收获过的作物。
- 选种时能看到哪些伙伴、哪项建设需要这种作物；材料不够的委托会直接带你去对应的作物和空田。
- 收成可以交付委托、用于建设、当作点心喂给伙伴，或者在集市出售多余的部分。

## 伙伴小桌：2048 与每日备种礼

「伙伴小桌」里是一局完整的 2048：用方向键、WASD、滑动或四个方向按钮移动，保留自动续盘、「悔一步」和最高纪录。键盘只在棋盘获得焦点时接管方向键，不会抢其他页面和表单的输入。

棋子换成了庭院里的东西，农田和棋盘用同一套作物图案，数字始终显示：

| 数字 | 棋子 | 数字 | 棋子 |
| --: | :-- | --: | :-- |
| 2 | 种子袋 | 128 | 萝卜篮 |
| 4 | 嫩芽 | 256 | 草莓篮 |
| 8 | 小萝卜 | 512 | 蓝莓篮 |
| 16 | 草莓 | 1024 | 荔枝篮 |
| 32 | 蓝莓 | 2048 | 荔宝丰收礼 |
| 64 | 荔枝 | | |

合到 4096 及以上会换上庆典装饰，完整数字照样显示。棋盘下方会提示这局合到了什么、下一阶是什么；完整的素材图鉴默认折叠。棋盘、分数和最高纪录保存在庭院存档里，刷新或重开应用可以接着下。

[查看 2048 的 11 种庭院棋子](../screenshot-arcade-garden-preview.png)（用预置棋盘展示图案，不是真实对局或得分）

**每日备种礼**：当天实际合出 128 或以上，可以领取一次。

- 内容：需要的种子 ×1、8 荔枝币、当前伙伴成长 +3、亲密度 +2、心情 +10，并记一次每日陪伴。
- 给哪种种子：优先补未完成委托和下一项建设的缺口，计算时会算上篮子里的收成、已有种子和正在生长的作物；不会给尚未解锁的种子。没有缺口时补一颗萝卜种子。
- 领完可以直接去播种。棋盘上留着的旧大数字，不能用来领取新一天的奖励。
- 棋盘上的图案不会直接变成农田库存，领了备种礼，这一局才接回种植。

第一次合出 128、256、512、1024、2048 时，会自动收下对应的里程碑贴纸，放在小屋收藏里。已领的奖励和贴纸不会因为悔一步或重开而退回，也不能重复领取。2048 不是庭院的必经关卡：只喜欢专注、种植或照料，也能把庭院建起来。

## 庭院集市：委托与出售

- 每天有三份伙伴委托，由伙伴们按日期轮流提出，只用已解锁的作物；当天的清单中途不会被替换。
- 交付后得到材料的售价，另加 3、3、4 币答谢，一天合计 10 币。
- 提出委托的那位伙伴获得成长 +5、亲密度 +3，不会错给当前选中的另一位伙伴。
- 材料不够时会显示还差多少，暂时不能交付。没有逾期惩罚，第二天换新委托。
- 累计交付 1、3、8、15 份时，分别收下感谢便笺、野餐邀请、好邻居木牌和伙伴相框。
- 「出售多余」会先留出当天未完成委托和下一项建设需要的收成，再卖掉剩下的；全部都有用时按钮不可点。这只限制出售，你仍可以拿这些收成喂伙伴或建造。
- 种子铺按上面的价格卖种子，未解锁的作物会标出解锁等级。食物 8 币一份。小屋装饰兑换后永久拥有，可以随时收起或摆出。

## 回忆与建设

收成和荔枝币可以变成看得见的庭院布置。满足开放条件后，消耗材料和荔枝币建造：

| 建设 | 开放条件 | 首次建造消耗 |
| :-- | :-- | :-- |
| 湖畔野餐角 | 累计收获 3 次 | 60 币 + 小萝卜 ×4 + 草莓 ×2 |
| 窗边育苗架 | 累计交付 3 份委托 | 120 币 + 草莓 ×4 + 蓝莓 ×3 |
| 湖畔灯径 | 累计交付 8 份委托 | 240 币 + 蓝莓 ×4 + 荔枝 ×3 |

第一次建成会自动摆放；之后收起或摆出都不再扣费。建好的布置会出现在首页、小屋和农田的像素场景里。

## 每日补给

「荔枝庭院」页顶部的「领取每日补给」每天可以领一次：20 荔枝币、1 份食物、2 颗萝卜种子。它和伙伴小桌的每日备种礼分开领取。

## 来访小故事与收藏

- 每在一个新的日子回来（不要求连续），就能在「荔园拾光」翻开下一段校园小故事，并收下一件纪念物，放进回忆册和小屋；一共七段。
- 隔几天再回来，进度不会清零；完成记录保存在本机。
- 小屋的「庭院收藏」集中展示 2048 的五枚里程碑贴纸、委托纪念物和来访故事的纪念物。
- 从旧版本升级的存档，缺少的任务日期和专注历史不会凭空补写；已有的累计值、伙伴成长和已领的纪念章都会保留。

## 庭院明信片

- **贯穿全应用**：所选环境会延伸到今日、学习书屋、校园服务、校园网、荔枝庭院和设置。每页顶部都有一扇同样光线的窗景，页名和导航里的名字一致；各页使用同样的纸面和导航。首页风景里的书屋、告示板、后院可以直接点进去，分别通向学习书屋、校园服务和荔枝庭院，普通文字导航始终可用。
- **不影响进度**：选择保存在本机，伙伴、农田和待办的进度不受影响；选完面板自动收起。已有存档默认是像素庭院。
- **伙伴名牌**：在三渲二风景里，伙伴平时只显示小名牌；摸头等互动后展开回应气泡，约 10 秒后收起。
- **资源占用**：首页展开完整风景，其他房间用紧凑窗景，笔记页再缩小，给正文留出位置。动画最高 30 帧/秒，页面滚出视野或窗口在后台时暂停。
- **关闭动画**：在「设置 → 风景与偏好」关闭「开启动画（伙伴与庭院风景）」，或者系统开启了「减少动态效果」时，风景显示静止画面。
- **设备不支持时**：设备不支持三维渲染（WebGL）时，保留像素校园和全部操作。

## 限制

- 桌面伙伴只在单显示器环境下实际验收过，物理多显示器还没实测；长时间运行的资源占用和睡眠唤醒后的表现也没有验收。透明区域点穿在真实用户桌面上还没有复核。
- 三渲二风景没有做过多机型的性能验收。
- 场景、角色和全部控件的美术还没有统一重制。
- 还没有开展真实同学试用，庭院的成长节奏和长期内容会根据试用反馈调整。
- 便携版没有独立的桌面伙伴和托盘。

当前未完成的事项汇总在 [开发状态](../STATUS.md#s1-1)。
