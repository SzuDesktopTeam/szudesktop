# 常见问题

这一页用几句话回答最常被问到的问题，每条后面都链接到讲得更完整的指南页。

## 接了自己的路由器后登录不上

校园网的每个接入点都有自己的编号（ac_id），这个编号跟着墙上的网口走，不跟路由器走；编号不对，认证会被直接拒绝。先在应用里点「运行网络诊断」，看区域和认证门户是否可达；想看识别出的接入点编号，用命令行 `szunet detect`。识别失败时，在「校园网」页的「高级设置 · 仅在接入点识别失败时修改」里手动填写，命令行则用 `--ac-id` 指定。

→ [校园网连接与命令行 szunet](network.md)。学校官方客户端接在路由器后也可能起不来，原因见博客[《深大校园网疑云：为什么我连路由器的时候，官方登录应用失败了？》](../blog/官方客户端为什么在路由器下失败.md)；各种报错原文见[校园网连不上排查指南](../深圳大学校园网连不上排查指南.md)。

## 杀毒软件或 SmartScreen 报警

安装包和便携版程序都没有数字签名，第一次运行会出现 SmartScreen 提示，部分杀毒软件也可能报警。请从 GitHub 发布页下载，并用同名 `.sha256` 文件核对；但不要把所有安全提示都当成误报，代码是开源的，可以自己查看、自己编译后比对。

→ [下载、安装与更新](install.md)

## 关掉窗口，程序还在吗

安装版关掉主窗口后，桌面伙伴和托盘还在，程序没有退出；要完整退出，用桌面伙伴菜单「退出应用」、托盘「退出」或「设置 → 关于与更新 → 退出应用」。便携版在所有窗口都关闭约 10 秒后自动退出。刷新页面不会结束服务。

→ [下载、安装与更新](install.md)

## 会不会在后台自动重连

不会周期性重连。除了你手动登录，程序只会在启动时最多用已记住的账号自动认证一次；安装版可以在「设置 → 桌面陪伴 → 启动时自动连接校园网」关掉，便携版用 `--no-auto-login` 启动。

→ [校园网连接与命令行 szunet](network.md)

## 账号密码存在哪

保存在系统的安全存储里：Windows 用 DPAPI 加密，只有这台电脑的当前账户能解开；macOS 用钥匙串；Linux 用 Secret Service。三个平台都没有明文兜底，保存不了会明确报错。在应用里只有认证成功并勾选「认证成功后记住账号密码」才会保存，随时可以在「设置 → 存档与隐私」点「删除已保存凭据」。

→ [数据、隐私与安全](data-and-privacy.md)

## Mac 或 Linux 能用吗

目前只能用命令行 `szunet` 连校园网，macOS（Intel / Apple 芯片）和 Linux（amd64 / arm64）都有对应的下载文件。桌面应用、桌面伙伴和托盘只有 Windows 版；macOS / Linux 桌面端在开发路线图上，但状态是待做，优先级较低。

→ [下载、安装与更新](install.md)、[校园网连接与命令行 szunet](network.md)

## 换电脑怎么迁移

庭院和课程笔记要分别导出：在「设置 → 存档与隐私」点「导出庭院与待办」和「备份课程笔记」，到新电脑上用「从备份恢复」和课程书架的「恢复整本备份」导回。校园网密码不在导出文件里，新电脑上要重新登录并勾选记住。

→ [数据、隐私与安全](data-and-privacy.md)

## 提示后台版本过旧或版本不一致

说明旧版 szuDesktop（包括便携版）的后台还在运行。先把旧版完整退出，再打开新版；如果提示「请重新安装当前版本」，重新运行当前版本的安装包。

→ [下载、安装与更新](install.md)

## 学校业务为什么显示测试中

课表、成绩、安装版的学校登录接回、应用内预约和学院琴房，都需要有相应权限的真实学校账号才能验收，目前还没有全部通过。这些功能可能读取失败或结果不完整，一切以学校系统为准。

→ [校园服务与学校登录](campus.md)

## 没找到答案

到 [Issues](https://github.com/SzuDesktopTeam/szudesktop/issues) 反馈，写清当时想做什么、卡在哪一步。「设置 → 关于与更新 → 反馈与建议」里可以复制不含个人信息的环境信息；请不要附密码、Cookie 或个人成绩。
