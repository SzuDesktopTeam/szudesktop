# 常见问题

这一页用几句话回答最常被问到的问题，每条后面都链接到讲得更完整的指南页。

## 接了自己的路由器后登录不上

校园网的每个接入点都有自己的编号（ac_id），这个编号跟着墙上的网口走，不跟路由器走；编号不对，认证会被直接拒绝。先在应用里点「运行网络诊断」，看区域和认证门户是否可达；想看识别出的接入点编号，用命令行 `szunet detect`。识别失败时，在「校园网」页的「高级设置 · 仅在接入点识别失败时修改」里手动填写，命令行则用 `--ac-id` 指定。

→ [校园网连接与命令行 szunet](network.md)。学校官方客户端接在路由器后也可能起不来，原因见博客[《深大校园网疑云：为什么我连路由器的时候，官方登录应用失败了？》](../blog/官方客户端为什么在路由器下失败.md)；各种报错原文见[校园网连不上排查指南](../深圳大学校园网连不上排查指南.md)。

## 浏览器拦下载、杀毒软件或 SmartScreen 报警

安装包和便携版程序都没有数字签名，所以会被拦一下：浏览器说这个文件不常被下载时，在下载列表里选「保留」（Edge 要先点文件旁的「…」）；第一次运行弹出「Windows 已保护你的电脑」时，点「更多信息」，再点「仍要运行」。部分杀毒软件也可能报警。只放行从 GitHub 发布页下载、用同名 `.sha256` 核对过的文件；但不要把所有安全提示都当成误报，代码是开源的，可以自己查看、自己编译后比对。

Windows 版需要 Windows 10 或 11（64 位），Windows 7、8 和 32 位系统用不了。

→ [下载、安装与更新](install.md)

## Mac 上提示无法打开或无法验证开发者

macOS 版未经 Apple 公证，第一次打开会被系统拦下，按系统版本放行一次即可：macOS 15 及以后，在提示框点「完成」，再到「系统设置 → 隐私与安全性」底部点「仍要打开」；macOS 13 和 14，在「应用程序」里按住 Control 点按 szuDesktop，选「打开」。每次更新到新版本都要再放行一次。放行前可以先用同名 `.sha256` 核对下载。

→ [下载、安装与更新](install.md)

## 关掉窗口，程序还在吗

Windows 安装版关掉主窗口后，桌面伙伴和托盘还在，程序没有退出；要完整退出，用桌面伙伴菜单「退出应用」、托盘「退出」或「设置 → 关于与更新 → 退出应用」。macOS 版关掉主窗口后，桌面伙伴和屏幕顶部的菜单栏图标还在；点程序坞图标就能找回主窗口，按 ⌘Q 或用菜单栏图标的「退出」完整退出。便携版在所有窗口都关闭约 10 秒后自动退出。刷新页面不会结束服务。

→ [下载、安装与更新](install.md)

## 会不会在后台自动重连

不会周期性重连。除了你手动登录，程序只会在启动时最多用已记住的账号自动认证一次；Windows 安装版和 macOS 版可以在「设置 → 桌面陪伴 → 启动时自动连接校园网」关掉，便携版用 `--no-auto-login` 启动。

→ [校园网连接与命令行 szunet](network.md)

## 校园网页写着「没有检测到校园网认证页面」

完整的提示是灰色的「外网正常；没有检测到校园网认证页面（不在校园网内时属正常）」。人在校外、用手机热点或家里的宽带时就是这样，不用处理。只有应用判定你在教学区或宿舍区、却查不到认证状态时，才会显示黄色的「校园认证待确认」，这时再点「运行网络诊断」。

→ [校园网连接与命令行 szunet](network.md)

## 开着代理软件，学校系统打不开或认证失败

Clash 这类代理软件的 Fake-IP 模式会把学校域名解析成 198.18 开头的假地址。网络诊断或学校服务的报错里出现「代理软件接管了学校域名」时，把 `szu.edu.cn` 设为直连，Fake-IP 模式还要把它加进 fake-ip-filter 这类「不分配假 IP」的名单，改好后再运行一次诊断确认。检查只认 IPv4 的假地址段，查不出来但又开着代理时，可以先临时关掉代理再试。

→ [校园网连接与命令行 szunet](network.md)

## 误删了笔记里的一段，或存档坏了

存档和笔记坏掉时会自动用 `.bak` 恢复；应用还会按天另存最近 3 个使用日的备份（`.bak-年-月-日`），可以完整退出应用后手动换回某一天。

→ [数据、隐私与安全](data-and-privacy.md)

## 账号密码存在哪

保存在系统的安全存储里：Windows 用 DPAPI 加密，只有这台电脑的当前账户能解开；macOS 用钥匙串的 `szunet` 条目，macOS 版和命令行版共用；Linux 用 Secret Service。三个平台都没有明文兜底，保存不了会明确报错。在应用里只有认证成功并勾选「认证成功后记住账号密码」才会保存，随时可以在「设置 → 存档与隐私」点「删除已保存凭据」。

→ [数据、隐私与安全](data-and-privacy.md)

## Mac 或 Linux 能用吗

**Mac**：可以用 macOS 桌面版，目前是预览版，需要 macOS 13 或更高版本。Apple 芯片选 `mac-arm64.dmg`，Intel 处理器选 `mac-x64.dmg`；功能和 Windows 安装版一致，有桌面伙伴，托盘换成屏幕顶部的菜单栏图标。第一次打开要手动放行（见上一条）。真机验收还一项都没做：浏览器下载后的首次放行、菜单栏与退出、学校和飞书窗口的「页面」菜单、登录时启动、系统通知、钥匙串、多显示器和 macOS 13 / 14 等都还要在真机上逐项确认（完整清单见[下载、安装与更新](install.md)页末），遇到问题请按[反馈说明](feedback.md)告诉我们，写上 macOS 版本、芯片和卡在哪一步。只想连校园网的话，也可以用命令行 `szunet`。

**Linux**：只能用命令行 `szunet` 连校园网（amd64 / arm64），没有桌面应用和桌面伙伴；Linux 桌面端在开发路线图上，状态是待做，优先级较低。

→ [下载、安装与更新](install.md)、[校园网连接与命令行 szunet](network.md)

## 换电脑怎么迁移

庭院和课程笔记要分别导出：在「设置 → 存档与隐私」点「导出庭院与待办」和「备份课程笔记」，到新电脑上用「从备份恢复」和课程书架的「恢复整本备份」导回。Windows 和 Mac 之间换电脑也是这样。校园网密码不在导出文件里，新电脑上要重新登录并勾选记住。

→ [数据、隐私与安全](data-and-privacy.md)

## 提示后台版本过旧或版本不一致

说明旧版 szuDesktop（包括便携版）的后台还在运行。先把旧版完整退出，再打开新版；如果提示「请重新安装当前版本」，重新运行当前版本的安装包。

→ [下载、安装与更新](install.md)

## 学校业务为什么显示测试中

课表、成绩、安装版的学校登录接回、应用内预约和学院琴房，都需要有相应权限的真实学校账号才能验收，目前还没有全部通过。这些功能可能读取失败或结果不完整，一切以学校系统为准。

→ [校园服务与学校登录](campus.md)

## 没找到答案

按[反馈说明](feedback.md)告诉我们，写清当时想做什么、卡在哪一步。「设置 → 关于与更新 → 反馈与建议」里可以复制不含个人信息的环境信息；网络或学校服务出问题时，再附上同一处的「复制诊断报告」，它只含结构，复制前可以先预览全文。请不要附密码、Cookie 或个人成绩。
