# 下载、安装与更新

这一页说明该下载哪个版本、怎么校验和安装，以及日常怎么打开、退出、升级和卸载 szuDesktop。Mac 上的安装、首次放行和操作差别集中在「macOS 版（预览）」一节。

## 选哪个版本

桌面应用有 Windows 版和 macOS 版。macOS 版目前是**预览版**：功能与 Windows 安装版一致，但有一部分行为还没在真机上验收（见页末「限制」）。Linux 只提供校园网命令行 `szunet`；Linux 桌面端列在开发路线图里，状态是待做，优先级较低。

| 平台 | 可以下载的 | 桌面应用 | 桌面伙伴与托盘 | 开机自启 |
| :-- | :-- | :-- | :-- | :-- |
| Windows x64 | 安装版、便携版、命令行 `szunet` | 有 | 仅安装版 | 有，需要自己开启 |
| macOS 13 或更高（Apple 芯片 / Intel） | macOS 版（DMG，预览）、命令行 `szunet` | 有（预览） | 有，托盘换成屏幕顶部的菜单栏图标 | 有，叫「登录 Mac 时启动」，需要自己开启 |
| Linux（amd64 / arm64） | 命令行 `szunet` | — | — | — |

表中「—」表示不支持。macOS 12 及更早的版本打不开 macOS 版。

Windows 上三种形态的区别：

| | 安装版 | 便携版 | 命令行 `szunet` |
| :-- | :-- | :-- | :-- |
| 窗口 | 自带独立窗口，不需要另装浏览器或开发环境 | 用本机的 Edge 或 Chrome 打开一个没有地址栏的窗口；两者都找不到时，用默认浏览器打开 | 没有窗口，在终端里使用 |
| 桌面伙伴 | 常驻桌面，可以点击照料、拖动、在 40%–200% 之间调大小 | 没有独立的桌面伙伴，庭院养成在窗口里照常进行 | — |
| 系统托盘 | 有 | 没有 | — |
| 学校和飞书原页面 | 在应用里的独立窗口打开 | 在系统浏览器里打开 | — |
| 适合 | 大多数同学 | 不想运行安装程序，只用单个程序文件 | 只要连校园网，或想写进脚本 |

安装版和便携版使用同一份本机庭院与学习记录，换着用不会丢进度。macOS 版和 Windows 安装版一样自带窗口，指南里写着「安装版」的功能 macOS 版也都有，操作上的差别见下面的 [macOS 版（预览）](#macos-版预览)。命令行的用法见[校园网连接与命令行 szunet](network.md)。

## 下载与校验

所有文件都在 [GitHub 发布页](https://github.com/SzuDesktopTeam/szudesktop/releases)。目前的版本都是测试版，发布页上标为预发布（Pre-release）。

| 文件 | 是什么 | 下载大小（约） |
| :-- | :-- | :-- |
| `szuDesktop-Setup-<版本号>.exe` | Windows 安装版 | 98 MB，自带窗口运行时 |
| `szudesktop-<发布标签>-windows-amd64.zip` | Windows 便携版，解压后双击里面的 `szudesktop.exe` | 6.5 MB |
| `szudesktop-windows-amd64.exe` | 便携版里的同一个程序，单文件下载 | 13 MB |
| `szuDesktop-<版本号>-mac-arm64.dmg` | macOS 版（预览），Apple 芯片（M1 及更新） | 123 MB |
| `szuDesktop-<版本号>-mac-x64.dmg` | macOS 版（预览），Intel 处理器 | 130 MB |
| `szunet-windows-amd64.exe` | 命令行，Windows x64 | 7.2 MB |
| `szunet-darwin-amd64` / `szunet-darwin-arm64` | 命令行，macOS Intel / Apple 芯片 | 7.0 MB / 6.5 MB |
| `szunet-linux-amd64` / `szunet-linux-arm64` | 命令行，Linux amd64 / arm64 | 6.8 MB / 6.4 MB |

大小按 beta0.9.5 的发布附件取整，每一版略有不同，以发布页上显示的为准；装好后占用多少磁盘还没有实测。

文件名里的 `<版本号>` 只有数字（形如 `x.y.z`，不带 beta），`<发布标签>` 是发布页上这一版的标签名（目前的测试版是 `beta` 加版本号）。拿不准时，对照发布页上的实际文件名。

每个文件都带一个同名的 `.sha256` 校验文件，可以用它确认下载完整、没有被改动：

- **Linux**：把程序和 `.sha256` 放在同一个文件夹，运行 `sha256sum -c szunet-linux-amd64.sha256`（换成你下载的文件名），显示 `OK` 即一致。
- **macOS**：同样放在一个文件夹，在「终端」里进入这个文件夹，运行 `shasum -a 256 -c szuDesktop-<版本号>-mac-arm64.dmg.sha256`（换成你下载的文件名，命令行版同理），显示 `OK` 即一致。
- **Windows**：在 PowerShell（系统自带）里运行 `Get-FileHash .\szuDesktop-Setup-<版本号>.exe -Algorithm SHA256`，把输出的值和用记事本打开的 `.sha256` 文件第一段比对（大小写不影响）。

校验值只能说明文件和发布页上的一致，不能代替发布者签名。

## 安装与首次运行

**Windows 安装版**：运行 `szuDesktop-Setup-<版本号>.exe`，安装时可以选择安装位置。装好后打开 szuDesktop 即可。

**Windows 便携版**：把 ZIP 解压到你想放的文件夹，双击 `szudesktop.exe`。

**macOS 版**：见下面的 [macOS 版（预览）](#macos-版预览)。

第一次打开后该做什么，见[快速上手](getting-started.md)。

### Windows：SmartScreen 与杀毒软件提示

安装包和便携版程序目前都**没有数字签名**，第一次运行时 Windows 会弹出 SmartScreen 提示，部分杀毒软件也可能报警。遇到这种情况：

1. 确认文件是从上面的 GitHub 发布页下载的，并用 `.sha256` 核对过。
2. SmartScreen 提示里选「更多信息」后，可以自己决定是否继续运行。

但请不要把安全软件的所有提示都笼统当成误报。代码是开源的，可以自己查看源码、自己编译（`go build`）后比对程序行为。

## macOS 版（预览）

macOS 版需要 macOS 13 或更高版本，按芯片分两个安装包。它是预览版：已经通过自动化的打包、安装和启动检查，但下面提到的一部分行为还没有人在真机上逐项验收，遇到问题请按[反馈问题](#反馈问题)一节告诉我们。

### 选哪个 DMG

打开「苹果菜单 → 关于本机」：

- 显示「芯片」（Apple M1、M2、M3、M4 等）：下载 `szuDesktop-<版本号>-mac-arm64.dmg`。
- 显示「处理器」（Intel）：下载 `szuDesktop-<版本号>-mac-x64.dmg`。

想确认下载完整，可以按上面「下载与校验」里的方法用 `shasum` 核对。

### 安装

1. 双击下载好的 `.dmg`，在打开的窗口里把 szuDesktop 拖到旁边的「应用程序」文件夹。
2. 从「应用程序」（或启动台）里打开 szuDesktop。拖完以后可以在 Finder 侧边栏把 DMG 推出。

请不要直接在 DMG 窗口里运行：从那里打开时，设置里的「登录 Mac 时启动」是灰色的，开不了。

### 第一次打开：放行

应用未经 Apple 公证，第一次打开会被系统拦下，提示无法打开或无法验证它。这不是文件损坏，按系统版本放行一次即可：

- **macOS 15 及以后**：在提示框里点「完成」，然后打开「系统设置 → 隐私与安全性」，在底部找到关于 szuDesktop 的提示，点「仍要打开」，再按提示确认（可能要输入 Mac 的登录密码）。
- **macOS 13 或 14**：在 Finder 的「应用程序」里按住 Control 点按 szuDesktop，选「打开」，在弹出的提示里再点「打开」。也可以用上面 macOS 15 的办法。
- **熟悉终端的话**：对核对过校验值的文件，也可以运行 `xattr -dr com.apple.quarantine /Applications/szuDesktop.app` 去掉下载标记，再正常打开。

每次更新到新版本，都要再放行一次。

### 第一次打开后，系统可能还会问

- **通知**：第一次专注提醒时，macOS 会询问是否允许 szuDesktop 发通知，请选择允许。之前选了不允许的话，到「系统设置 → 通知」里找到 szuDesktop 打开。通知发不出去时，应用会改由桌面伙伴冒气泡提醒，程序坞图标也会跳动；没允许通知时这个替代提醒能不能出现，还没在真机上确认。
- **本地网络**（macOS 15 及以后）：如果系统询问 szuDesktop 能否查找本地网络上的设备，请选择允许，应用要靠它连接校园网认证门户、检测登录状态。之前拒绝过的话，到「系统设置 → 隐私与安全性 → 本地网络」里打开 szuDesktop。在校园网里是否一定会弹出这个询问，还没有实测。

### 菜单栏图标、程序坞与「页面」菜单

| 做什么 | Windows 安装版 | macOS 版 |
| :-- | :-- | :-- |
| 托盘 | 任务栏通知区域的托盘图标：单击打开主窗口，右键弹出菜单 | 屏幕顶部菜单栏里的 szuDesktop 图标：单击弹出菜单 |
| 找回主窗口 | 点托盘图标，或伙伴菜单「打开主窗口」 | 点程序坞里的 szuDesktop 图标，或菜单栏图标 / 伙伴菜单的「打开主窗口」 |
| 完整退出 | 托盘「退出」、伙伴菜单「退出应用」、「设置 → 关于与更新 → 退出应用」 | ⌘Q、程序坞右键「退出」、菜单栏图标「退出」、伙伴菜单「退出应用」、「设置 → 关于与更新 → 退出应用」 |
| 打开伙伴菜单 | 左键或右键点伙伴 | 点击或右键伙伴；触控板双指轻点、按住 Control 点按也可以 |
| 调整伙伴大小 | 悬停时滚动滚轮，每次 10 个百分点 | 悬停时滚动鼠标滚轮，或在触控板上双指上下滑动 |
| 学校和飞书窗口的返回、刷新等 | 窗口自己的菜单「学校页面」「课程共学」 | 屏幕顶部菜单栏的「页面」菜单 |
| 登录系统时自动启动 | 「设置 → 桌面陪伴 → 登录 Windows 时启动」 | 「设置 → 桌面陪伴 → 登录 Mac 时启动」 |

- **菜单栏图标**：就是 Windows 上的托盘，菜单里有「隐藏宠物 / 显示宠物」「宠物置顶」「宠物大小」「勿扰（暂停专注提醒）」「打开主窗口」和「退出」。右键（或按住 Control 点按）程序坞里的 szuDesktop 图标，也有前面这几项，退出用程序坞菜单自带的「退出」。
- **关闭主窗口**：点窗口左上角的红色按钮或按 ⌘W，主窗口只是藏起来，桌面伙伴和菜单栏图标还在，程序没有退出；全屏时会先退出全屏再藏起来。再从「应用程序」打开一次也会显示原来的主窗口，不会启动第二份。
- **「页面」菜单**：学校和飞书窗口在 Mac 上没有自己的菜单栏，返回、前进、刷新、在系统浏览器打开、清除本次学校登录和关闭窗口，都在屏幕顶部菜单栏的「页面」菜单里，跟着当前在前面的那个窗口变（飞书窗口只有返回、刷新、在系统浏览器打开和关闭）。没有打开学校或飞书窗口时，这些项是灰色的。菜单栏还有「编辑」菜单，在学校登录框和飞书文档里可以用 ⌘C、⌘V、⌘Z 这些快捷键。
- **按 ⌘H 隐藏应用**：桌面伙伴会跟着一起隐藏。在菜单栏图标里点「显示宠物」只把伙伴带回来；点程序坞图标找回主窗口。
- **桌面伙伴**跟着你切换桌面，全屏应用里也看得到。更多操作见[荔枝庭院与伙伴](garden.md)。

### 退出、注销与关机

- 各种退出方式效果相同：退出前先保存课程笔记和 2048 棋局；保存不住时弹框，让你选择返回处理还是放弃修改。
- 注销或关机时也一样先保存。如果这时弹出了上面的框，macOS 会提示「szuDesktop 中断了注销」，处理完再注销即可。

### 登录 Mac 时启动

- 在「设置 → 桌面陪伴 → 登录 Mac 时启动」开启，默认不开启；开启后登录时只出现桌面伙伴和菜单栏图标，不弹出主窗口。
- 要先把 szuDesktop 放进「应用程序」并从那里打开，否则开关是灰色的，旁边会提示原因。
- 如果提示需要批准，到「系统设置 → 通用 → 登录项与扩展」（macOS 13、14 上叫「登录项」）允许 szuDesktop。
- 更新版本后如果登录时不再启动，把这个开关关掉再打开一次。

### 更新

1. 先在「设置 → 存档与隐私」点「导出庭院与待办」和「备份课程笔记」留一份备份。
2. 完全退出旧版：按 ⌘Q，或点菜单栏图标的「退出」。
3. 打开新版 DMG，把 szuDesktop 拖进「应用程序」，提示已有同名项目时选择替换。
4. 按上面「第一次打开：放行」再放行一次，然后打开。

庭院存档和笔记在 `~/.szunet`，校园网账号在钥匙串里，替换应用不会动它们。在「设置 → 关于与更新 → 版本与更新」点「检查更新」后，卡片下方也会提示这几步。

### 卸载与彻底清除

- **卸载**：完全退出后，把「应用程序」里的 szuDesktop 拖进废纸篓。庭院存档、课程笔记和钥匙串里的账号都不会被删除。
- **想连数据一起清掉**：先在「设置 → 存档与隐私」点「删除已保存凭据」，删掉钥匙串里的 `szunet` 条目（也可以在「钥匙串访问」里手动删）；如果「钥匙串访问」里还有 `szunet-session` 条目，也一并删除。再删除 `~/.szunet` 文件夹和 `~/Library/Application Support/szuDesktop` 文件夹。`.szunet` 是隐藏文件夹，在 Finder 里按 ⌘⇧. 可以显示，或用 Finder 的「前往 → 前往文件夹…」直接输入路径。删除前记得导出需要保留的备份。
- 钥匙串的 `szunet` 条目和命令行 `szunet` 共用：如果你还在用命令行版，删掉后命令行也要重新保存账号。

## 打开与退出

### Windows 安装版

- **再次打开**：程序已在运行时再打开一次，会把已有的窗口带到前面，不会启动第二份。
- **复用后台**：如果同版本的便携版后台服务已经在运行，安装版会直接用它，不另起一份。
- **关闭主窗口**：桌面伙伴和托盘图标仍在，程序没有退出。要回到主窗口，在桌面伙伴的菜单里选「打开主窗口」，或点托盘图标。
- **完整退出**：桌面伙伴菜单「退出应用」、托盘菜单「退出」、「设置 → 关于与更新 → 退出应用」，三种方式效果相同。
  - 退出前会先保存课程笔记。保存失败时默认回到应用让你处理，只有明确选择放弃未保存的修改才会继续退出。
  - 完整退出只结束这次启动的后台引擎；复用的已有后台服务（例如便携版的）会保留。
  - 学校窗口里的登录只保留到完整退出；只关主窗口不会清除它。详见[校园服务与学校登录](campus.md)。

macOS 版的打开与退出见上面的 [macOS 版（预览）](#macos-版预览)，学校窗口的登录同样只保留到完整退出。

### 便携版

- 再次双击 `szudesktop.exe` 会让已在运行的程序打开窗口，不会再启动第二份后台。
- 刷新页面不会结束服务。
- 所有窗口都关闭约 10 秒后自动退出；想立刻退出，用「设置 → 关于与更新 → 退出应用」。
- 便携版重启后，之前留在浏览器里的旧标签页不能再用，请从 szuDesktop 重新打开窗口。
- 只想启动后台服务、不打开窗口时，可以从命令行运行 `szudesktop.exe --no-open`。

### 启动时的提示

- **「当前后台引擎版本较旧，请先退出旧版 szuDesktop 再打开」或「正在运行的后台程序与当前版本不一致，请先退出旧版 szuDesktop（包括便携版）后再打开」**：安装版启动时会核对窗口程序和后台程序的完整版本号（包括 beta 标记）。旧版（包括便携版）还在运行时，先把它完整退出，再打开新版。安装版不会为了启动新窗口而擅自关掉已有的便携版后台。
- **「后台引擎与应用版本不一致，请重新安装当前版本」**：安装目录里的程序版本对不上，重新运行当前版本的安装包即可。
- **「应用正在启动或退出，请稍后再打开」**：通常是刚退出又马上重开，稍等片刻再打开。
- **macOS 版启动失败**：按提示稍等几秒再打开；仍然失败时，在「活动监视器」里结束名称含 szudesktop 的残留进程或重启 Mac，必要时重新下载 szuDesktop、重新拖进「应用程序」。

## 开机自启

| 形态 | 怎么开启 | 说明 |
| :-- | :-- | :-- |
| Windows 安装版 | 「设置 → 桌面陪伴 → 登录 Windows 时启动」 | 默认不开启，只有你主动打开才会登记；开机时不弹出主窗口；卸载时一并清除 |
| Windows 便携版 | 「设置 → 桌面陪伴」里的「开机自启」卡片 | 登录 Windows 时静默启动，并自动连接一次校园网；需要界面时再双击程序打开。可以在这里或 Windows 的「启动应用」里关闭 |
| macOS 版 | 「设置 → 桌面陪伴 → 登录 Mac 时启动」 | 默认不开启；要先把应用放进「应用程序」；登录时不弹出主窗口。需要批准时到「系统设置 → 通用 → 登录项与扩展」允许，细节见上面的 [macOS 版（预览）](#macos-版预览) |
| 命令行 | `szunet autostart` | 仅 Windows，用法见[校园网连接与命令行 szunet](network.md) |

读不到自启状态时，界面会明确提示原因，不会猜成「未开启」。命令行 `szunet autostart` 在 macOS / Linux 上不支持，会明确提示。

## 启动时自动连接校园网

- **Windows 安装版和 macOS 版**：在「设置 → 桌面陪伴 → 启动时自动连接校园网」关闭，下次启动生效。
- **便携版**：从命令行运行 `szudesktop.exe --no-auto-login`。

什么时候会连、什么时候跳过，以及在应用里怎么登录和记住账号，见[校园网连接与命令行 szunet](network.md)。

## 检查更新

程序**没有自动更新**，不会自己下载或安装新版本。

在「设置 → 关于与更新 → 版本与更新」里可以手动检查：

1. 在「更新渠道」里选「测试版（含正式版）」或「仅正式版」。
2. 点「检查更新」。只有点了这个按钮，程序才会联网查询 GitHub 发布页。
3. 有新版本时点「前往下载更新」，否则可以点「查看发布说明」。下载后由你自己运行安装包（Mac 上是把新版拖进「应用程序」）完成更新。

## 升级

1. **先备份**：在「设置 → 存档与隐私」分别点「导出庭院与待办」和「备份课程笔记」。庭院备份不包含课程笔记，两份都要导出。
2. **完整退出旧版**：包括正在运行的便携版，否则新版打开时可能提示版本不一致。
3. **Windows 安装版**：下载新版安装包直接运行，装到原来的位置。升级会保留庭院、学习记录、加密保存的账号配置和桌面伙伴设置，并清理旧版本的程序文件。
4. **Windows 便携版**：下载新版 ZIP 解压，用新的 `szudesktop.exe` 替换旧的即可。数据在用户目录的 `.szunet` 文件夹里，不在程序旁边。
5. **macOS 版**：把新版拖进「应用程序」替换旧版，再放行一次，见上面的 [macOS 版（预览）](#macos-版预览)。

更新程序不会清空存档。Windows 跨版本安装升级与数据保留的验证记录见[开发状态](../STATUS.md#s67)；macOS 版这是第一个版本，跨版本升级还没有验证。备份文件怎么恢复，见[数据、隐私与安全](data-and-privacy.md)。

## 卸载

- **Windows 安装版**：在 Windows 的应用列表里卸载 szuDesktop。卸载只移除程序：用户目录 `.szunet` 里的庭院存档、课程笔记和加密保存的账号不会被删除，桌面伙伴设置也会保留；如果开启过「登录 Windows 时启动」，自启项会一并清除。
- **Windows 便携版**：如果开过「开机自启」，先在设置或 Windows 的「启动应用」里关掉，再删除程序文件夹。
- **Windows 上想连数据一起清掉**：先在「设置 → 存档与隐私」点「删除已保存凭据」，再手动删除用户目录下的 `.szunet` 文件夹。安装版的桌面伙伴大小、位置和桌面设置另存在 `%APPDATA%\szuDesktop`，卸载时不会删除，要彻底清除也一并删掉这个文件夹（校园网账号密码不在这里）。删除前记得导出需要保留的备份。
- **macOS 版**：见上面的 [macOS 版（预览）](#macos-版预览)。

## 反馈问题

「设置 → 关于与更新 → 反馈与建议」里有「复制环境信息」，只复制版本、系统类型和界面模式三行，不包含学号、成绩、密码、Cookie 或存档。网络或学校服务出问题时，同一张卡片里还有默认折叠的「诊断报告 · 先预览，再复制」，只含结构、不含具体值，包含哪些内容见[数据、隐私与安全](data-and-privacy.md)。点「提交反馈 ↗」会打开 GitHub，需要 GitHub 账号。

macOS 预览版遇到问题时，在 [Issues](https://github.com/SzuDesktopTeam/szudesktop/issues) 选「问题反馈」，写上 macOS 版本（「关于本机」里能看到）、芯片（Apple 芯片或 Intel）、卡在哪一步和提示原文，比如放行时看到的提示、菜单栏图标或伙伴哪里不对。请不要附密码、Cookie 或个人成绩。

## 限制

- macOS 版是预览版，真机验收还一项都没做。浏览器下载后的首次放行、菜单栏图标与程序坞、关窗与全屏、各种退出方式先保存、学校和飞书窗口的「页面」菜单与复制粘贴、桌面伙伴的 Control 点按与多显示器、系统通知的授权与弹出、注销与登录时启动、钥匙串里账号的保存与读取、macOS 13 和 14，以及在校园网里是否弹出「本地网络」授权，都还要在真机上逐项确认。
- macOS 版未经 Apple 公证，每次更新都要重新放行；不支持 macOS 12 及更早版本；主窗口和伙伴都隐藏时，专注提醒可能稍有延迟；这是第一个 macOS 版本，跨版本升级还没有验证。
- Linux 只有命令行 `szunet`，桌面端还在待做列表中，优先级较低。
- Windows 安装包和程序都没有数字签名；各平台都没有自动更新，新版需要手动下载安装。
- Windows 安装版开启「登录 Windows 时启动」后，重新登录 Windows 时是否真的启动还没有实测。
- 便携版没有独立的桌面伙伴和托盘；便携版重启后，旧浏览器标签页要从 szuDesktop 重新打开。
- 长时间运行的资源占用、睡眠唤醒后的表现还没有验收。

这些事项的当前进度见[开发状态](../STATUS.md#s1-1)，macOS 版的逐项验收见[开发状态：macOS 待真机验收](../STATUS.md#s68-2)。
